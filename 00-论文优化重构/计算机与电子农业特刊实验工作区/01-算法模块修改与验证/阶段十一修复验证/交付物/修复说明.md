## 修复内容（10 节计划，全部落地）

### §二 GT 与评测口径
- `gt_audit_convert.py`：纯几何+颜色启发式把每个 GT shape 推断为
  plant / pot / reference_cube / ignore；cube 永不进入 plant / potted GT。
- 产出：`GT口径拆分审计/gt_masks_split/<sample>/mask_{plant_only|plant_plus_pot|reference_cube}_{frame}.png`
  + `gt_mapping_*.json` + `gt_pending_review.csv`（无低置信帧被静默采用）。
- 实验一脚本 `convert_labelme` 增加 `target_scope` 与 `--legacy_union_gt` 开关；
  `METHOD_GT_SCOPE` 按方法名选择 GT 口径（P2 去盆 / 带盆方法含盆）。

### §三 SAM3 候选生成
- `Candidate` 扩展 `instance_id / box / sam_score / mask_threshold / source_stage / prompt_mode`。
- `--candidate_mode {legacy_union, per_instance}`（默认 per_instance）：
  逐实例独立候选，**生成阶段不 OR、不做最大连通域**；旧 legacy_union 行为完整保留可复现。
- `--sam3_mask_threshold`（默认 0.5）、`--save_raw_instance_masks`（默认 True）用于阶段证据。

### §四 评分修复
- §4.1 空掩膜硬门：`score_candidate` 空掩膜直接返回 total=0、empty_flag=True，不再因时序默认满分得高分。
- §4.2 SAM 实例 score 进入评分：`q_sam = sigmoid(6*(sam_score-0.5))`，权重 `sam`。
- §4.4 边界置信度改为边缘贴合度（`edge_quality`）：不再奖励"边界越少越好"，细叶多边界不再自动低分。
- §4.5 时序 IoU 门控：`--use_temporal_alignment` 默认关，未配准时序项置中性 0.5（不默认满分）。
- §4.6 硬门控：纵向覆盖不足（`vertical_coverage_min_ratio`）/ track 重叠低（`box_track_overlap_min`）→ 风险惩罚。
- §4.7 重提示触发：`select_mask` 返回 4 元组，top1-top2 分差 < `reprompt_score_gap`(0.05) 或空/低分 → needs_reprompt。

### §五 P2/P6 语义坍缩
- `BUILTIN_PROMPTS` 新增 `POT="flowerpot and tray"`、`CUBE="blue calibration cube"`。
- `detect_semantic_collapse`（面积差比与盆区覆盖差比均 <0.05 → 坍缩）。
- `compose_plant_only` / `compose_potted` 受控组合（植株候选并集 − POT 候选；P6 = plant_only ∪ POT）。

### §六 深色叶与花盆混淆
- ExG 降级为弱特征；`semantic_pot_lower_start_ratio` 保留但 pot 删除需 POT 候选/几何证据共同支持。
- per_instance 模式默认 `keep_largest_component=False`，最终仅删明显微小且无关联组件。

### §七 SPNP
- `--spnp_min_refined_iou` 默认 0.10 → **0.65**（范围 0.60–0.75 可配），接受时额外检查植株覆盖下降与 pot/cube 泄漏。
- 正提示改为 track-backed core（证据引导）；无 evidence 时正框不再强制用整 mask 大 bbox。

### §八 A6/A7（默认关）
- A6：`--use_cross_view_consensus` 默认 False；新增 `--use_cross_view_registration`（默认关）。
- A7：`--memory_seed_mode` 新增多锚点；`select_single_object_id` 单对象 ID 选择，禁止 OR 所有 object ID。

### §九 测试
- `tests/test_phase11.py`：9 个单元测试（GT 拆分 / per_instance 候选 / 空掩膜评分 / P2-P6 坍缩 / A6 开关 / A7 单 ID），全部通过。
