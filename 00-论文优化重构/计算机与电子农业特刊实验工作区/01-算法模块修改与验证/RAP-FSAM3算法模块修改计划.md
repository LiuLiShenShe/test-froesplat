# RAP-FSAM3-v2 算法模块修改计划

## 目标

把当前 FSAM3 从“FFT 筛帧 + SAM3 文本提示分割 + PCA 主前景筛选”的流程，扩展为面向植物三维重建的 RAP-FSAM3-v2。新版重点不再强行强调旧 A3-A5 的独立增益，而是围绕已经验证有效的 A2 结构化正负提示，新增 A1s 语义门控选择和 A5c 重建一致性修正，形成更完整的农业重建适配链路。

## 当前基线

现有 FSAM3 主要包含：

- FFT 频域帧质量筛选。
- SAM3 文本提示植物分割。
- 闭运算修补孔洞。
- 8 连通域过滤。
- PCA 主前景稳定性筛选。

该基线已经能形成较稳定的植物前景先验，但对计算机与电子农业特刊而言，还需要更明确体现“基础视觉模型的农业任务适配”。

## 目标流程

```text
输入多视角 RGB 图像
  -> FFT 帧质量筛选
  -> 多提示词 SAM3 候选掩膜生成
  -> A1s：语义门控可靠性评分与候选选择
  -> 结构化正负提示细化
  -> A5c：重建一致性修正提示
  -> 保护性残差修复、重提示日志和几何日志
  -> 输出最终掩膜、前景图、透明图和可靠性日志
```

旧版 A3 残差修复、A4 重提示检测和 A5 几何反馈已经实现并完成阶段八冒烟，但在 `KongQueZhuYu` GT5 和 `XianKeLai1` GT1 上没有显示稳定的独立二值指标增益。新版把它们降级为保护性链路和诊断日志，正式实验三主消融改为 A0、A1、A1s、A2、A5c。

## 命令行超参开关规范

RAP-FSAM3 必须沿用现有 2DGS 的“统一入口 + 命令行开关”风格。所有新增模块都用 `--xxx` 参数控制，默认关闭或设为 `none`，保证不传新参数时不会改变旧版 SAM3/FSAM3 行为。

### 基础路径参数

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `--input_dir` | 必填 | 输入图像目录，建议使用 `数据管理/01-输入图像/02-fft_frames/<样本名>`。 |
| `--output_dir` | 必填 | 输出目录，建议使用 `数据管理/03-分割Mask/05-RAP-FSAM3掩膜/<样本名>`。 |

### 默认行为要求

```bash

  --input_dir <图像目录> \
  --output_dir <输出目录>
```

必须等价于单提示词基线，不启用多提示词选择、不启用正负提示、不启用残差修复、不启用重提示检测、不启用几何反馈。这样才能保证旧版基线纯净，也方便实验三逐步消融。

## 模块一：A1s 语义门控多提示词候选选择

### 目的

降低单一文本提示带来的语义偏差，并修复旧 A1 仅凭几何/面积/对比评分时可能选错提示词的问题。`XianKeLai1` GT1 诊断显示 P2 candidate 对 GT 最好，但旧 A1 自动选择 P3 后召回下降，因此新版 A1s 必须把“植物主体”和“花盆/桌面/邻近植物”等干扰物显式纳入选择评分。

### 候选提示词

| 编号 | 提示词 | 优势 | 风险 |
| --- | --- | --- | --- |
| P1 | `green plant` | 召回绿色植物区域 | 容易包含绿色背景 |
| P2 | `entire plant excluding pot` | 符合去花盆植物体目标 | 仍可能局部包含土壤或支撑物 |
| P3 | `leaves and stems` | 强调叶和茎 | 可能漏掉粗茎或花叶混合结构 |
| P4 | `crop seedling` | 适合幼苗形态 | 容易低分割成熟植株 |
| P5 | `plant body without background` | 去背景较稳定 | 对花盆排除不如 P2 明确 |

### 可靠性评分

每个候选掩膜计算综合可靠性：

```text
S = 基础可靠性得分 + 语义门控得分 - 干扰物惩罚

基础可靠性得分 = 面积合理性 + 连通域 + 边界 + 时序稳定 + 前背景对比
语义门控得分 = target_box_score + center_prior_score
干扰物惩罚 = pot_overlap_penalty + side_distractor_penalty
```

当前脚本还额外记录 `下方区域占比`、`下方泄漏得分`、`侧边区域占比` 和 `侧边泄漏得分`。默认 `--score_weights` 不包含 `leak` 或 `side`，因此旧命令不受影响；当需要抑制花盆等下方泄漏时，可显式设置类似 `--score_weights area=1,comp=1,edge=1,temp=1,contrast=1,leak=2`。当需要测试侧边邻近植物泄漏时，可显式加入 `side` 并配合 `--leakage_side_mode left/right/both`。

建议记录的指标：

| 指标 | 含义 | 趋势 |
| --- | --- | --- |
| 面积合理性 | 前景面积是否处在合理范围内 | 越高越好 |
| 连通域得分 | 连通域数量是否不过多 | 越高越好 |
| 边界得分 | 边界是否稳定、不过度破碎 | 越高越好 |
| 时序稳定得分 | 相邻帧掩膜是否平稳 | 越高越好 |
| 前背景对比得分 | 前景与背景颜色差异是否明显 | 越高越好 |
| 下方泄漏得分 | 候选掩膜在图像下方区域的占比是否过高 | 越高越好 |
| 侧边泄漏得分 | 候选掩膜在图像左右边缘区域的占比是否过高 | 越高越好 |
| 目标框一致性 | 候选 bbox 是否贴合植物主体框 | 越高越好 |
| 花盆/桌面重叠 | 候选是否覆盖干扰物框 | 越低越好 |
| 侧边干扰重叠 | 候选是否粘连邻近植物或边缘干扰 | 越低越好 |
| 中心主体先验 | 候选主体是否落在当前盆栽中心区域 | 越高越好 |

### 语义框来源

短期实现不强依赖外部模型，可先使用启发式伪框：

- 植物主体框：由高置信候选的 union bbox、前景颜色聚类或默认中心区域估计。
- 花盆/桌面框：由图像下方区域、非绿色低饱和/橙棕区域和现有下方泄漏特征估计。
- 侧边干扰框：由左右边界带内的大面积绿色连通区域估计。

中期可接入 Grounding DINO / Grounded SAM 风格的开放词汇框，提示词包括 `plant`、`potted plant`、`pot`、`table`、`background plant` 和 `support`。

### 输出

- 每帧被选中的提示词编号。
- 每个提示词候选的评分。
- 最终选择或融合后的掩膜。
- 提示词敏感帧标记。

## 模块二：结构化正负提示

### 目的

减少花盆、土壤、支撑物、桌面和绿色背景进入植物前景。

### 方法

- 正样本点从初始植物掩膜内部生成，优先选择距离边界较远的主体区域。
- 负样本点从掩膜外扩环带生成。
- 如果花盆区域明显，可在植物下方或疑似花盆区域额外放置负点。

### 重要约束

如果当前 SAM3 接口不支持点提示，不应声称修改了 SAM3 内部结构。可以把该模块实现为 SAM 系列二次细化，或实现为掩膜后处理阶段的结构化提示校正。

## 模块三：保护性残差修复与边界细化预留

### 目的

在修补孔洞和去噪的同时，保护细叶、叶柄、叶尖和窄叶片。当前实现已经能保存细结构残差，但在已标注样本上独立增益较弱，因此新版把它定位为保护性后处理；后续如接入 HQ-SAM、BiRefNet 或 edge-band refiner，可升级为 A3b 边界感知细化模块。

### 建议流程

```text
闭运算掩膜 = 对原始掩膜做闭运算
开运算掩膜 = 对闭运算掩膜做开运算
细结构残差 = 被开运算删除、但与主植物区域邻近或连通的细长区域
最终修复掩膜 = 开运算掩膜 并入 细结构残差
```

### 细结构恢复条件

- 该区域来自闭运算掩膜，但被开运算删除。
- 与主植物连通域邻近或轻微膨胀后相接。
- 形状细长或位于叶片边界附近。
- 面积较小，避免恢复大块背景。

## 模块四：A5c 重建一致性修正提示

### 目的

检测并修正由于遮挡、反光、背景相似、视角变化或提示词敏感导致的掩膜质量突降帧。旧 A5 主要输出几何 `low/ok` 和最终重提示标记，新版 A5c 必须把几何反馈转化为正负提示或局部 delta mask，使完整模块产生真实可量化的掩膜改动。

### 掩膜与图像稳定性信号

可综合：

- 相邻帧掩膜 IoU 下降。
- 前景面积突变。
- 相邻帧图像结构相似度变化。
- 边界破碎或边界漂移。

超过阈值时，将该帧标记为需要重新提示、降低训练权重，或进入 A5c 几何修正。

### 几何反馈

如果已有 COLMAP 稀疏点轨迹，可将前景稀疏点投影回图像，检查投影点是否落在掩膜内部。若大量前景几何点落在掩膜外，说明该帧可能欠分割；若大块掩膜区域没有几何支撑，可能存在背景误分。A5c 不只记录该现象，还要生成修正提示：

| 场景 | 信号 | A5c 修正 |
| --- | --- | --- |
| 欠分割 | 前景 track 投影点落在 mask 外 | 生成正点/正框，局部扩展 mask |
| 过分割 | 大块 mask 区域缺少几何支撑 | 生成负点/负框，局部删除泄漏 |
| 突变帧 | 相邻帧 IoU/面积/边界突变 | 触发修正或降低该帧训练权重 |
| 修正过强 | 修正后与 A2 IoU 低于阈值 | 拒绝修正，回退到 A2 |

当前实现补充：

- 几何反馈优先按 COLMAP 图像 stem 与最终掩膜 stem 精确匹配。
- 对 `XianKeLai1` 这类 COLMAP 图像名为 `crop_0000.png`、输入图像名为 `0000.jpg` 的样本，已支持去掉 `crop_` 前缀后匹配，并在 `几何反馈.csv` 记录 `mask_stem`。
- `KongQueZhuYu` A5 10 帧小批量中几何分数均低于 0.7 并标记为 `low`，视觉检查确认存在绿色花盆和邻近绿色植物泄漏，因此该失败模式需要在正式实验前处理。

## 模块五：A6 跨视角全局共识投票（2026-08-25 新增）

### 目的

解决 `KongQueZhuYu` 等样本已确认的侧边邻近植物粘连问题。逐帧独立推理下首帧错误不会传播，因此可以对全序列选中掩膜做全局投票：真目标随转台在几乎所有视角居中存在，邻株只从部分方位入镜且偏离中心，跨视角共识 + 中心先验可以把这类干扰剔除，同时保护目标完整边界。

### 流程

```text
S1 稳健中心估计：全帧 A1s 选中掩膜 bbox 中心取中位数 → 中心置信带
S2 逐像素支持频率图：N 帧选中掩膜堆叠统计 freq(x,y)
S3 中心加权投票：support = freq × w(center_dist)，偏心高频干扰物被降权
S4 几何共识通道：复用 COLMAP 前景 track 投影支撑
   - 低票且无几何支撑 → 删除（过分割修正）
   - 高票且有几何支撑 → 补回（欠分割召回）
S5 共识参考掩膜 → 逐帧 delta 修正
S6 安全回退：修正后与原掩膜 IoU < --consensus_fallback_iou 则拒绝该帧修正
```

### 参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--use_cross_view_consensus` | 关 | A6 总开关 |
| `--consensus_support_ratio` | 0.55 | 高票阈值 |
| `--consensus_low_vote_ratio` | 0.30 | 低票阈值 |
| `--consensus_recall_ratio` | 0.70 | 补回通道阈值 |
| `--consensus_center_band_ratio` | 0.35 | 中心置信带半宽下限 |
| `--consensus_center_decay` | 0.65 | 距中心带衰减系数 |
| `--consensus_geometry_dilation` | 19 | 几何支撑膨胀核 |
| `--consensus_fallback_iou` | 0.75 | 回退 IoU 阈值 |
| `--consensus_min_frames` | 5 | 触发最少帧数 |

### 输出

- `共识投票掩膜/`：每帧共识后掩膜
- `共识投票.csv`：每帧接受/拒绝、回退 IoU、删除/补回像素比例
- `日志/共识汇总.json`：全局汇总

## 模块六：A7 SAM3 记忆预测器接入（2026-08-25 新增）

## 2026-08-25 冒烟收口（KongQueZhuYu 10 帧）

### 粘连帧修正（S5b 粘连切割）

邻株与目标物理重叠成单一连通域时，最大连通域过滤与形态学开运算均无法分离。最终方案改为几何通道切割：

- **根因一**：bbox 中位数中心先验被邻株泄漏本身污染（中位 bbox 宽度达图像宽 94%，中心带覆盖全图），所有偏心测试失效 → 改用"全帧常在 ∩ COLMAP track 支撑"核心像素估计稳健中心与带宽。
- **根因二**：回退 IoU 作为硬门会拒绝正确的大幅修正（粘连切割天然低 IoU）→ 回退 IoU 降级为诊断记录，共识掩膜始终进入终选。
- **终选裁决**：Pass 2 新增 `--consensus_variant_leak_weight`（冒烟取 1.5），对"偏离中心带且无 track 支撑"像素占比扣分；含邻株的 A1s 变体自然落败。

冒烟结果：0005/0007/0008/0009 各切除约 0.4%-2% 图像面积的邻株粘连区；GT 帧 0000 F1=0.9742/IoU=0.9496 与基线持平（目标完整性保持）。

### A7 记忆预测器接入

- 播种提示为 **文本 + 种子帧共识掩膜归一化 xywh 框**（纯文本会把同语义邻株一并检出）；
