# Phase 15 — Challenge GT Annotation Guide

## 任务

从 `difficulty_ranking.csv`（60 个难度候选帧，跨 14 个非 GT sample）中挑选 30-60 帧，
用 labelme 手工标注，输出到 `/data/fj/F2DMAS/03-GT-区分_challenge/<sample>/<frame>.json`。

## 查看候选

- 排名表：`挑战集列表/difficulty_ranking.csv`（按 composite difficulty 降序）
- 缩略图：`挑战集列表/candidates_p1.png`（12 行 × 5 列，60 帧全部可见，标签 `#rank sample_frame D=难度`）

## 建议挑选策略

- 优先选 D 值高（≥0.58 左右）且视觉上确实难的帧：植物过小、叶片密集交错、背景杂乱、目标被遮挡。
- 保证多样性：至少覆盖 5 个不同 sample，每个 sample 最多 ~5 帧。
- 避免：完全没有植株的帧、纯黑色/纯白背景无目标、极端重复姿态。

## 标注格式（与现有 GT 完全一致）

每个帧一个 JSON（labelme 格式），labels 用：

| label | 含义 | 必需? |
|---|---|---|
| `potted_plant` | 整株盆栽（含盆） | 必须 |
| `plant` | 仅植株（叶+茎，不含盆） | 建议（formal_p2 需要） |
| `pot` | 花盆/托盘 | 建议（formal_p2 需要） |
| `blue_cube` | 蓝色标定块（如有） | 如存在则标 |

参考现有标注：`/data/fj/F2DMAS/03-GT-区分/CaoMei1/0000.json`。

结构：
```json
{
  "version": "0.4.43",
  "flags": {},
  "shapes": [
    {"label": "potted_plant", "text": "", "points": [[x1,y1],[x2,y2],...], "shape_type": "linestrip"}
  ],
  "imagePath": "0000.jpg",
  "imageData": null,
  "imageHeight": 2160,
  "imageWidth": 3840,
  "text": ""
}
```
