# 实验二：提示词鲁棒性与失败模式实验方案

## 优先级

最高。该实验应在模块消融前执行，用于证明单一提示词在农业场景中并不稳定，从而合理引出多提示词选择和 RAP-FSAM3。

## 当前状态

`KongQueZhuYu` GT5 的实验二提示词鲁棒性表已经填入，P1-P5 与多提示词选择结果已统一评估，并已生成 P2 vs P4 的提示词差异图板。当前结论足以支撑“提示词会显著影响 FSAM3 前景掩膜质量”：P2 在该子集上最稳定，P4 基本失效，P3/P5 存在主体召回不足。

2026-06-06 补充判断：实验二不应只停留在 `KongQueZhuYu` GT5，否则只能证明某个样本上 prompt 不稳定，难以支撑“农业盆栽场景普遍存在 prompt bias”。当前四样本代表集 `E1_Representative4_PottedPlant_VFM` 已有 `KongQueZhuYu`、`DouBanLv1`、`ChangShouHua2`、`CaoMei1` 的 5 帧 GT 和 P1-P5 候选掩膜，可直接扩展为 **4 样本 × 5 帧 × 5 prompt = 100 条 2D 评估**。该补强只需要分割指标和失败图，不要求每个 prompt 进入 2DGS。

实验二后续从“可选扩展”改为“小成本必补”：保留 `KongQueZhuYu` GT5 作为主叙事例子，同时增加四样本 prompt robustness 附表和跨样本失败图板。`XianKeLai1` GT1 可继续作为 A1/A1s 机制例子放在实验三，不再作为实验二扩展的首选。

## 核心问题

不同文本提示词在盆栽植物场景中是否会产生不稳定的前景掩膜？多提示词选择是否能够降低这种不稳定性？

## 假设

- P1 容易包含绿色背景。
- P2 整体较稳定，但不同形态下仍有边界和少量泄漏差异。
- P3 可能漏掉粗茎或花叶混合结构。
- P4 可能低分割成熟植株。
- P5 在部分样本上比预期更保守，可能出现空掩膜或主体召回不足。
- 多提示词选择应降低背景泄漏、连通域破碎和时序波动。

## 对比方法

| 编号 | 提示词或方法 | 说明 |
| --- | --- | --- |
| P1 | `green plant` | 宽泛绿色植物提示 |
| P2 | `entire plant excluding pot` | 默认整株去花盆提示 |
| P3 | `leaves and stems` | 叶和茎提示 |
| P4 | `crop seedling` | 幼苗提示 |
| P5 | `plant body without background` | 去背景植物体提示 |
| 多提示词选择 | 选择可靠性最高的候选掩膜 | RAP-FSAM3 关键组件 |
| 多提示词融合 | 加权融合候选掩膜 | 可选组件 |

## 数据范围

- 主结果：使用四样本代表集 20 帧人工 GT，覆盖 `KongQueZhuYu`、`DouBanLv1`、`ChangShouHua2`、`CaoMei1`。
- Prompt 候选：复用 `../06-实验一四样本代表集/E1_Representative4_PottedPlant_VFM/rap_runs/RAP-FSAM3-v2/*/候选掩膜/P1_绿色植物` 到 `P5_去背景植物体`。
- 分割指标：对 P1-P5 全部 100 个候选掩膜计算 F1、mIoU、HD95、边界 F、面积比例、连通域、时序 IoU、泄漏能量。
- 稳定性指标：四样本内部逐样本计算，不跨样本混算相邻帧时序 IoU。
- 视觉例子：选择 4-6 个代表性失败场景，包括绿色背景、花盆泄漏、粗茎漏检、花叶混合、成熟植株欠分割和细结构丢失。

## 四样本补强设计

### 目标

把结论从“`KongQueZhuYu` 上 P4 失败”升级为“单提示词在不同植物形态下存在系统性不稳定”。主文只需放一个小表和一个失败图板，完整逐帧结果放 supplementary。

### 推荐样本角色

| 角色 | 推荐样本 | 证据口径 | 用途 |
| --- | --- | --- | --- |
| P2 表现好的样本 | `DouBanLv1` 或 `ChangShouHua2` | P2 在 5 帧上 F1 约 0.97，HD95 低于 `KongQueZhuYu`，泄漏较低 | 说明并非所有 prompt 都失败，P2 是合理但脆弱的默认提示 |
| P3 或 P5 失败明显样本 | `DouBanLv1` 优先，`ChangShouHua2` 备选 | `DouBanLv1` 上 P3/P5 多帧空掩膜或主体召回失败；`ChangShouHua2` 上 P5 对花叶混合结构保守 | 展示语义提示从“叶和茎/植物体”到真实盆栽目标之间存在形态偏差 |
| P4 几乎空掩膜成熟植株样本 | `DouBanLv1` 或 `ChangShouHua2`，保留 `KongQueZhuYu` 作原始例子 | P4 `crop seedling` 在非幼苗/成熟或规整盆栽样本上 5 帧接近全空 | 证明 P4 失败不是 `KongQueZhuYu` 个例，而是幼苗语义和成熟盆栽形态不匹配 |
| 低冠层/重叠叶补充 | `CaoMei1` | P2 仍可用但 HD95 较高，P3/P5/P4 明显不稳 | 展示形态更小、更低、更重叠时 prompt 影响边界和召回 |

### 当前四样本快速汇总

下表来自现有候选掩膜的同口径快速复算，用于决定补实验方向；正式数值应由固定脚本重新写入结果表。

| Prompt | 20 帧 F1 | 20 帧 mIoU | HD95 px | 边界F | 面积CV | 泄漏能量 | 结论 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| P1 `green plant` | 0.7972 | 0.7908 | 685.41 | 0.3313 | 0.582 | 0.000958 | 召回不足，部分样本偏保守 |
| P2 `entire plant excluding pot` | 0.9692 | 0.9624 | 193.71 | 0.4051 | 0.415 | 0.002272 | 四样本中最稳，适合作默认正例 |
| P3 `leaves and stems` | 0.6471 | 0.6789 | 2178.94 | 0.2019 | 1.029 | 0.001449 | 多样本主体召回不足或空掩膜 |
| P4 `crop seedling` | 0.0768 | 0.4199 | 3922.74 | 0.0423 | 2.387 | 0.000058 | 非幼苗/成熟盆栽形态下系统性欠分割 |
| P5 `plant body without background` | 0.4051 | 0.5455 | 3304.98 | 0.1009 | 1.804 | 0.000220 | 去背景语义过保守，多样本空掩膜 |

逐样本重点现象：

- `DouBanLv1`：P2 F1=0.9742，P3 F1=0.3235，P4/P5 F1=0.0000；最适合同时作为 P2 正例和 P3/P5/P4 失败例。
- `ChangShouHua2`：P2 F1=0.9733，P5 F1=0.2948，P4 F1=0.0000；适合展示花叶混合或密集冠层下 P5/P4 失败。
- `CaoMei1`：P2 F1=0.9460，但 HD95=500.2；适合展示低冠层/重叠叶时即使 P2 可用，边界仍不稳定。
- `KongQueZhuYu`：继续保留原有 P4 全空和 P3/P5 主体召回不足图，作为历史闭环样本。

### 推荐图表组织

主文图可做成 3 行或 4 行失败图板：

| 行 | 样本帧 | 展示列 | 说明 |
| --- | --- | --- | --- |
| A | `DouBanLv1_0050` 或 `DouBanLv1_0075` | RGB、GT、P2、P3、P5 | P2 好，P3/P5 空或漏检 |
| B | `ChangShouHua2_0025` 或 `ChangShouHua2_0075` | RGB、GT、P2、P4、P5 | 花叶混合/成熟盆栽下 P4/P5 失败 |
| C | `CaoMei1_0000` 或 `CaoMei1_0100` | RGB、GT、P2、P3、P4 | 低冠层重叠叶下提示敏感和边界偏差 |
| D 可选 | `KongQueZhuYu_0025` 或 `KongQueZhuYu_0075` | RGB、GT、P2、P4、RAP-FSAM3-v2 | 与原实验二图板衔接，说明多提示词选择避免坏 prompt |

主表不必展开 4×5×5 全部逐帧。建议主文放“Prompt × 20 帧均值表”，supplementary 放“Prompt × Sample 均值表”和逐帧失败记录。

### 最小执行步骤

1. 复用四样本代表集中的 P1-P5 候选掩膜和 GT，按实验一同口径计算 2D 指标。
2. 生成两个结果表：`实验二_提示词鲁棒性四样本汇总表.csv` 和 `实验二_提示词鲁棒性四样本逐样本表.csv`。
3. 更新 `实验二_失败模式记录表.csv`，新增 `DouBanLv1`、`ChangShouHua2`、`CaoMei1` 的失败帧路径。
4. 生成跨样本失败图板，至少包含 P2 正例、P3/P5 明显失败、P4 空掩膜三个场景。
5. 写作时明确：该补强是 2D segmentation robustness analysis，不声称这些失败 prompt 都已进入 2DGS。

## 指标

| 指标 | 作用 |
| --- | --- |
| F1 | 衡量整体前景分割质量 |
| mIoU | 衡量区域重叠 |
| HD95 | 衡量边界和离群误差 |
| 边界 F 分数 | 衡量叶缘和叶柄边界质量 |
| 时序 IoU | 衡量相邻帧稳定性 |
| 面积变异系数 | 衡量前景面积波动 |
| 每帧连通域数 | 衡量破碎和误分 |
| 外部非黑比例 | 衡量背景泄漏 |
| 泄漏能量 | 衡量背景残留强度 |

## 失败模式

| 类型 | 含义 |
| --- | --- |
| 绿背景误分 | 绿色背景被选为植物 |
| 花盆误分 | 花盆、土壤或容器进入前景 |
| 粗茎漏检 | 粗茎或主茎未被完整识别 |
| 花叶混合错误 | 花和叶语义混合导致掩膜不稳定 |
| 成熟植株欠分割 | 幼苗提示不能覆盖成熟植株 |
| 细结构丢失 | 细叶、叶柄或叶尖丢失 |
