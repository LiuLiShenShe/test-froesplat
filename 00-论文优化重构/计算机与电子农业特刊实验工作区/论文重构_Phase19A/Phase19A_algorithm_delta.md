## 4. Rewrite Instructions (for Phase 19B)

1. **§2.3.3 → rewrite as "Instance Ranking" (R1):** replace the `c_i^(k)`/softmax selection with the R1 policy. Recommended formula (WP5-audited, `Phase19A_formula_audit.md` §3.1):
   ```
   F = B − q_contrast / 5.5 − P,   B = (q_area + q_comp + q_edge + q_temp + q_contrast + 0.5·q_sam) / 5.5
   P = 0.25·1[V < 0.30] + 0.15·1[track_mask valid ∧ IoU < 0.20]   (semantic_total = 0, gate off)
   selection = argmax (F, tie_break), tie_break = 0.0 under R1
   ```
   Note: `denom = 5.5` must stay explicit; `q_contrast` is subtracted as `q_contrast/5.5` (not 1.0), because the weights sum stays frozen at 5.5 (`ranking_policy.py`).
2. **Keep the softmax-gated selector in the ablation** (Table 5 geometry-only row, F1=0.8429) described as the superseded/diagnostic selector whose ranking failure motivated R1.
3. **Do not introduce A6/A7 stage language** in Method. Keep the Discussion future-work mention of temporal propagation.
4. **§2.3.2:** change "five fixed prompts, K=5 per frame" to per-instance candidate generation; state the production default prompt list is P2 (`prompt_list="P2"`), with the five-prompt catalogue as the available prompt set.
5. **Vocabulary:** name the frozen evaluation set "frozen P6 evaluation set" (21 annotated frames); never equate "P6 prompt set" with "P6_raw_baseline run" (`Phase19A_formula_audit.md` §4).
6. **Terminology guard:** "multiview mask consistency" (§3.3 track filtering) must not be conflated with the A6 cross-view consensus mechanism.
