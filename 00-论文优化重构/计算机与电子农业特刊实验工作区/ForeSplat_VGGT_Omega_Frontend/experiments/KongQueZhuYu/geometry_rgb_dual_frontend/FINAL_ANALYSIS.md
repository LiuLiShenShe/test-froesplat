# ForeSplat 原始 RGB 双前端 208 帧与完整 GGGS 对照

两套208帧前端、E8/E10/E7/E9各30,000步及E1/E5六模型统一208训练视角浮点评价均已实际执行。本次续接完成真实渲染、点云的直接视觉核验和最终决策，未重复训练或覆盖E1–E6。

**恢复背景几何上下文是本株重建退化的主要可修复因素。相机、跨视角深度、叶片轮廓和大尺度斑纹均明显改善；细叶脉、细锯齿与薄表面仍没有完全恢复。标准VGGT已不落后于Ω，当前GGGS照片重建建议以标准VGGT＋修正接口E10作为默认实验基线，保留E9为最高照片指标对照；后续NKSR直接Mesh优先使用Ω原始RGB预测后的完整前景Point Map。**两项推荐分别考虑照片重建和薄结构输入证据，不将照片指标最高等同于Mesh输入最好。

几何 RGB 使用审计适配器：Mask 外为02-FFT原图、Mask 内为逐像素不变的03-SAM前景；同时保存完整原图路径。训练 RGB/Mask、权重、优化损失和增密参数保持原配方。标准模型保留square1024→518，Ω保留balanced@512。

所有正式实验均在物理GPU1，经uv运行。共同208帧为0–209排除历史损坏44/206，没有增减。各前端使用深度反投影Point Map，保留原始Camera/Depth/Confidence；未新增learned point head或融合算法。Ω沿用既有融合，标准沿用原分层点采样，因此E8/E10并非同融合算法消融。

## 九项最终技术决策

1. **Ω改善多少？** 208帧前景极线3.0012→0.4793px（−84.03%），前景RGB-Depth7.7322→1.4827px，支持77.73%→91.36%，>90°跳变2→0。E7在原接口下相对E1已提高4.5988dB，说明几何RGB收益独立存在。
2. **标准VGGT改善多少？** 前景极线23.4907→0.4159px（−98.23%），前景RGB-Depth107.6193→1.1032px，支持22.06%→91.91%，>90°跳变12→0。E9相对E5提高10.8626dB。旧13.11dB的大部分可恢复差距来自本株的去背景几何输入条件；不能计算所有原因的唯一因果占比。
3. **标准是否仍明显落后？** 在相机、相邻深度和统一GGGS照片指标上已经不落后，E10略优于E8。分辨率差异仍存在：Ω有效网格384×688，标准portrait内容约291×518；原p20筛选后的固定叶缘查询保留率却是Ω51.01%、标准13.83%。标准照片更好与薄边点保留更少同时成立；其confidence未跨模型校准，不能把保留率直接称准确率。
4. **接口有独立收益吗？** Ω照片收益+0.7224dB，标准−0.0678dB；两者真实投影偏差和背景Alpha均改善。报告两种结果，继续保留修正接口，标准不宣称获得独立照片收益。
5. **E8/E10能提高17.89/13.11dB吗？** 能。统一重算E1/E5为17.8947/13.1057dB，E8/E10为23.2159/23.9005dB，分别+5.3212/+10.7949dB；FG、Edge、SSIM、LPIPS也改善。这是单株Seed0训练视角的明显数值提升，没有独立多种子统计显著性或未见视角泛化证明。
6. **叶缘、纹理、薄表面真正改善吗？** 真实RGB与原生局部图确认轮廓和大尺度斑纹改善，前景内侧边缘PSNR E1→E8 +3.2682、E5→E10 +5.7611dB。细叶脉、细锯齿仍软，原始共同Mask边界深度支持只有约52%，修正版仍有背景Alpha/射线残留；薄表面、双层和断裂未获绝对3D验证。下一步应定位GGGS残余监督与薄结构表达，不能再把所有模糊归给相机。
7. **Gaussian数量合理了吗？** E7/E8/E9/E10分别517,932/501,507/541,994/576,396，回到与旧E1的600,458同一量级；E10比旧E5的5,153,165减少88.81%。filtered-alpha<.05比例旧E5=64.94%、E10=20.92%，归一化尺度中位也不再极小。四组各144次增密事件无Q=0或denom-zero事件，未更改增密算法。数量恢复不能证明全部点有效，旧E5未保存的Q历史仍不能反推。
8. **默认前端选谁？** 以本次GGGS照片重建为目标，选择标准VGGT原始背景输入＋修正接口E10作为当前默认实验基线。理由包括近像素几何、稳定轨迹、FG/Edge/SSIM/LPIPS/梯度共同优势，以及相比E9更少背景高Alpha；不只依据PSNR。Ω/E8保留为薄边与效率对照：其推理更快、显存更低、固定叶缘保留和Alpha轮廓更好。本轮没有证明标准适合全部19株，也未修改生产代码的默认路由。
9. **后续NKSR用哪份前景Point Map？** 优先[VGGT_Omega_Original_RGB/foreground.ply](VGGT_Omega_Original_RGB/foreground.ply)及配套逐帧foreground_world_points/valid_foreground、原始Depth/Confidence/Camera/Pixel Transform。该PLY含13,640,966个原Mask＋原p20筛选的深度反投影点，未经新增融合；固定共享叶缘查询保留51.01%相对标准13.83%，且相机/深度已改善。保留标准的7,794,589点前景PLY为对照。不要以E8的Gaussian中心或COLMAP融合后的1,204,476点代替完整Point Map，不混合两套任意尺度。这里仅给出优先候选，未运行NKSR，也未证明Mesh结果必然更好。
