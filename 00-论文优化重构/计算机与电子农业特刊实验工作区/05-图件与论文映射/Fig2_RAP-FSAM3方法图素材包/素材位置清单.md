# Fig.2 RAP-FSAM3 方法图素材位置清单

图名建议：

`RAP-FSAM3: reconstruction-aware prompt-adaptive foreground-prior generation`

推荐主样本：`DouBanLv1_0000`。

推荐理由：这帧的 prompt 差异非常直观。P2 被语义门控稳定选中，P1/P3 只覆盖主要叶片区域，P4/P5 为空掩膜；后续正负提示点、几何修正和 final prior 都有完整真实输出，适合用一株样本讲完整流程。

素材包目录：

`00-论文优化重构/计算机与电子农业特刊实验工作区/05-图件与论文映射/Fig2_RAP-FSAM3方法图素材包`

## 图注要点

建议图注强调三点：

- RAP-FSAM3 不依赖单一 prompt，而是先产生多 prompt 候选并执行语义门控选择。
- 正负提示点来自植物主体、花盆/土壤/背景/外扩环带的结构化采样，不是人工随意点击。
- 几何一致性修正利用稀疏重建支持点补齐边界，输出稳定的 foreground prior 供后续 foreground-object 2DGS 使用。
