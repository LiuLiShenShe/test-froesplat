### 1. 实验一的 GT 子集太小，必须扩大或解释

你现在的 VFM 横向对比是在 **S23 统一 6 帧 GT 子集** 上做的。这个可以作为快速验证，但如果作为主实验，会被审稿人攻击样本太少。尤其你要投的是 COMPAG 特刊，审稿人会问：6 帧能不能代表不同植物、不同背景、不同叶片形态？

建议最低限度扩展到：

**6 个代表性样本 × 每个样本 5 帧 = 30 帧 GT。**

样本最好覆盖：目前已经有的孔雀竹芋、豆瓣绿、长寿花、草莓

* KongQueZhuYu：复杂背景/大叶片；
* XianKeLai1：细结构/边界敏感；
* CaoMei2：低冠层/重叠叶；
* 一个花叶混合样本；
* 一个绿色背景相似样本；
* 一个成熟密集冠层样本。

如果时间不够，至少做到 **3 个样本 × 每个样本 5 帧 = 15 帧 GT**。6 帧太容易被认为是 cherry-picking。

### 2. Prompt 鲁棒性实验不能只放 KongQueZhuYu GT5

实验二现在主要是在 `KongQueZhuYu` GT5 上比较 P1-P5。这个能说明 prompt 不稳定，但不能说明“农业场景普遍存在 prompt bias”。建议至少补 3 个样本：

* 一个 P2 表现好的样本；
* 一个 P3 或 P5 失败明显的样本；
* 一个 P4 几乎空掩膜的成熟植株样本。

你不一定要每个都跑 2DGS，只要给出 2D 分割指标和失败图即可。这样结论可以从“在某个样本中 P4 失败”提升为“单提示词在不同植物形态下存在系统性不稳定”。

### 5. 实验五现在还不是严格因果实验

你现在的实验五是“人工-虚拟表型一致性”，它能证明 ForeSplat 最终能测量，但不能证明“RAP-FSAM3-v2 比 SAM3/SEEM 更能降低表型误差”。

严格版本应该是：

| Mask source        | Plant height MAE | Canopy width MAE | Leaf length MAE | Leaf width MAE | Bias |
| ------------------ | ---------------: | ---------------: | --------------: | -------------: | ---: |
| SAM3 single prompt |                  |                  |                 |                |      |
| FSAM3-base         |                  |                  |                 |                |      |
| RAP-FSAM3-v2       |                  |                  |                 |                |      |

如果全量做太贵，建议做 **3 个样本的小闭环**，每个样本测株高、冠幅、叶长、叶宽。哪怕样本少，也能作为 “sensitivity analysis”，不要写成大规模表型验证。

这一组不是必须大，但非常加分，因为它把 VFM 改进和农业表型结果真正连起来。

## 还需要补的非性能实验

### 1. 时间成本和交互成本

特刊审稿人会关心 foundation model 的实际部署价值。你现在有 F1、mIoU、HD95、leakage，但还缺：

* 每帧/每序列 RAP-FSAM3-v2 运行时间；
* A0、A2、A5c 相比 SAM3 单提示词增加多少时间；
* 是否需要人工点击；
* 是否可以自动运行。

建议加一个小表：

| Method             | Manual interaction | Time/frame | Time/sequence | Notes                   |
| ------------------ | -----------------: | ---------: | ------------: | ----------------------- |
| SAM3 single prompt |                  低 |            |               | 单 prompt                |
| RAP-FSAM3-v2       |                低/无 |            |               | multi-prompt + geometry |
| U-Net/DeepLab lite |               需要训练 |            |               | 少量标注泛化弱                 |

你的优势应该写成：**不是最快，但减少人工标注和人工修 mask；相比监督模型，跨序列小样本泛化更稳。**

### 2. 失败案例要单独成图

你现在已经有失败案例图，建议明确归类成 4 类：

* green background leakage；
* pot/soil confusion；
* flower-leaf mixed structure；
* mature canopy under-segmentation；
* thin petiole / leaf-edge loss。

并且每类下面写：SAM3 单 prompt 如何失败，RAP-FSAM3-v2 如何修正，仍然有哪些不可修复情况。

这会让论文显得更真实，也能降低审稿人对“只报好结果”的怀疑。

### 3. 统计显著性或置信区间

如果你扩到 15/30 帧 GT，可以加 mean ± std。最好对 A0 vs A2、A2 vs A5c 做一个简单 paired test。A5c 提升很小，不一定显著，所以写作要谨慎：

* A2：主要性能提升，可能显著；
* A5c：边界和几何一致性补充，不强调显著大幅提升。
