# 工作区-数据管理双层映射

## 用途

本文件用于把两层内容对应起来：

- **论文整理层**：`计算机与电子农业特刊实验工作区/`，存放方案、结果表、论文图件、source_data、图板说明和论文映射。
- **底层运行层**：`数据管理/`，存放原始图像、GT、掩膜、COLMAP、2DGS 输出、评测原始 CSV、训练日志和可复现实验产物。

后续补实验时，原则是：先把新原始运行结果放入 `数据管理/05-评测结果/Sxx_*` 或对应数据目录，再把论文要用的汇总表、图件和 source_data 同步到本工作区。

## 补实验操作顺序

1. 在 `数据管理/05-评测结果/` 下新建连续编号目录，例如 `S27_*`。
2. 把原始输入引用、运行命令、逐帧 mask、评测 CSV、训练日志、2DGS/网格结果放入该目录或在 README 中记录真实位置。
3. 将论文需要的 `summary_metrics.csv`、`frame_metrics.csv`、表型误差表或 2DGS 汇总表复制/生成到工作区对应 `source_data/`。
4. 更新 `04-结果表格模板/` 中对应实验表。
5. 更新 `05-图件与论文映射/<实验目录>/figure_asset_index.csv` 和 `图板说明.md`。
6. 更新 `00-索引与计划/实验状态板.md`、`05-图件与论文映射/论文映射.md` 和本映射表。
