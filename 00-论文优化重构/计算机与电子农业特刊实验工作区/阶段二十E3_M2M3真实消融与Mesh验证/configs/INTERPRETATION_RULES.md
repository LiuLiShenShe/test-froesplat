# Interpretation rules established before formal M1/M2 results

本补充判读规则在三场景 M0 参考 Mesh 完成后、正式 M1/M2 结果出现前记录；不改变已冻结实验参数。它不引入用验证结果选阈值的质量门槛。

1. 剪枝事件、removed_count 与 floor_blocked_count 证明执行行为；只有对应实际变化和目标代理的证据，才讨论收益。算法触发与收益分别判断。
2. M0→M1 同时呈现 Gaussian 紧凑性、全图外观、固定前景代理、背景 RGB/alpha、结构/覆盖与成本，不合成总分。若紧凑性收益伴随场景或指标间退化，标记 MIXED 并列出负结果。只有一场景一个 seed，不作稳定性或统计显著性声明。
3. M1→M2 若全部 floor_blocked_count=0，容量保护的实际收益判为 NO_EFFECT / NOT_TRIGGERED。相同初始化并不保证 CUDA 原子操作、增密与后续训练完全逐位确定；未触发 floor 时的小幅差异不能归因于 Floor40。
4. Mesh 可重载、非空、有限坐标是恢复成功的必要条件，不证明真实几何准确。面片/组件/面积变化不能独立决定质量。必须结合固定视角可见覆盖、边界、深度一致性和直接图件，保留结构缺失与失败。
5. 主 TSDF 结果始终使用冻结参数。预声明 voxel×0.5/×2 的补充试验仅说明敏感性，不能替换主结果或据此选择模型。
6. 三场景与验证视角均不能替代多次独立训练；历史 M0 seed0 缺初始 RNG 存档的限制必须保留。M0 复用依据是源代码/配置等价，不是假称拥有历史初始状态哈希。
7. 论文方法只能改写为真实加权额外剪枝与特定路径的全局容量下限。无 model-to-mask deficit、局部 Floor40、边界效用或额外 deficit 增密；不得用本次结果为这些不存在的机制背书。
