# 实际图件查看记录

记录者为本次编码助手，使用本地图片查看工具直接读取真实输出，不是人工 GT 签署或外部识图 API 结论。图件由保留的完整三角 Mesh CPU raycast 生成；共同 M0 坐标框、相机和光照见 `reports/*_SURFACE_VIEW.json`。这是补充可视化，不是基于质量选择的验证相机。

- WanNianQing1 M0：raw/post 中都可辨认盆栽及叶片表面；raw 周围有较多黑色薄片/散点，post 明显移除其中一部分。叶片仍可见开口、交叠与不完整表面，无法据此证明真实叶片厚度/完整性。
- CaoMei2 M0：raw 有大量穿过植物附近的斜向黑色/灰色片状结构；post 去除了大部分外部组件，保留盆体与可见叶面，但局部孔洞、粗糙和缺失仍明显。这里不能把“图更干净”直接等同于植物几何更准确，尤其不能排除真实孤立叶片被同样删除。
- HongZhang M0：raw/post 均可辨认盆、茎叶与红色花部。raw 周围有黑色射线状/片状结构；post 减少但未全部消除这些结构。没有依据将每个外部表面都判定为真实 floating Gaussian，也没有真实几何 GT 判断表面偏差。

固定 held-out 重投影图还直接显示了 RGB、alpha 与深度可能给出不同背景信息：黑背景外观可以仍带有高 alpha 支持。图中 Gaussian 与 Mesh 法向分别保留其实际坐标约定，不以颜色相似冒充独立法向精度。

本记录只涉及 M0；M1/M2 完成后另行补充真实比较，不提前断言 M2 最优。结构结论以 CSV 和真实文件为准，视觉观察不替代可复算统计。

## 退化面诊断口径

原生后处理调用 `remove_degenerate_triangles()`；本阶段结构脚本另用 `||cross|| <= max(bbox_diagonal²×10^-12,10^-20)` 统计几何近零面积面。原生删除调用与这一诊断阈值不等同，因此 post Mesh 仍有非零诊断退化比例并不说明重载出错。没有按该新诊断阈值再次清理、平滑或修补模型；raw/post 的原始文件和重载结果全部保留。法向有限检查也不等同于每个近退化面都具有可靠单位法向。
