三个主提取都完成了 Gaussian PLY 与 checkpoint 张量一致性检查、冻结相机 depth/alpha 渲染、bounded TSDF、原始 Mesh、原生连通分量后处理、文件重读和结构统计重算。确切模型路径、输入哈希、浮点渲染、时间与内存见逐场景 `reports/*_M0_MESH_RUN.json` 和外部资产索引。

后处理 `num_cluster=1` 明确保留最大组件，因此后处理组件数为 1 是规则的直接结果，不是重建更准确的证据。CaoMei2 和 HongZhang 的原始最大组件分别仅占约 66.5% 与 76.7% 面片，后处理可能删除真实但孤立的叶片或细结构；保留 raw 结果并使用同一冻结 ROI 覆盖和深度重投影描述这种损失。

可重载、有限坐标和大量面片证明恢复流程可执行。大量边界、小组件及少量退化面说明结构仍有异常；不能仅据面片/顶点更多、组件更少或法向更平滑判定几何精度更高。全部长度/面积仍为任意 COLMAP 单位及其平方。

真实固定视角图中 RGB 黑背景可以与 ROI 外高 alpha 同时存在，背景外观抑制不等于无外部几何支持。Alpha/depth/normal、原始 Mesh 与后处理 Mesh 分别展示。没有引入人工 GT、真实三维 GT、厘米尺度或 Chamfer/F-score。
