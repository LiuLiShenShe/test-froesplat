# Phase20F 输入与执行门

Phase20E-3 仅交付真实 Mesh、机制消融和证据，不开展表型测量，不修改论文正文。模型索引见 `MESH_REFERENCE_MANIFEST.csv`、`M2M3_TRAINING_RUNS.csv`，Mesh 路径/哈希/协议见 `MESH_EXTRACTION_RUNS.csv` 和 `MESH_STRUCTURE_METRICS.csv`。下一阶段不得根据本次单种子外观或面片数量选择“最佳几何模型”作为真值。

## 尚缺的真实输入

| 表型 | 必需的物理尺度与定义 | 必需的对应实测 |
|---|---|---|
| 株高 | 每场景尺度锚点、地面/盆沿参考平面、重力方向、株高上下端定义 | 同株同采集时刻、单位明确的高度实测，测量工具与不确定度 |
| 冠幅 | 物理尺度、水平平面与冠幅方向（最大径/正交径）定义 | 同株两个方向的冠幅及方向记录，不能将相机坐标包围盒直接作为冠幅 |
| 叶长 | 物理尺度、叶片身份、叶柄是否包含、沿曲面或直线长度定义 | 对应叶片的标识及同一测量定义的长度实测 |
| 叶宽 | 物理尺度、同叶身份、最大宽度与测量平面/曲面定义 | 对应叶片宽度、测量位置与记录 |

还需说明样本ID、拍摄/测量日期、植株是否变形、测量重复次数和缺失值原因。现有历史工作簿缺少可恢复 COLMAP-to-physical scale 的标尺/marker/控制距离证据，不能仅凭数值列推导相机重建尺度。

## 明确的后续决策

1. 先恢复与场景相对应的真实尺度锚点及测量记录；没有这些输入时只开展任意 COLMAP 单位的可重复算法检查，不输出 cm/mm 或厘米误差。
2. 基于冻结 B_R0 Seed0 的参考模型和本阶段统一主 TSDF 协议建立测量接口；原始和后处理 Mesh 都保留，不能把被后处理删除的叶片假定为无关区域。
3. 对每项表型预定义参考平面、植株/叶片身份与缺失结构处理规则，再冻结测量方案；不使用本阶段模型之间的 Mesh 差作为真实测量误差。
4. 有了物理尺度与独立实测后才评估绝对误差、相对误差及重复测量不确定度。无独立几何 GT 时仍可提供重载完整性、组件/边界/法向、同相机深度一致性与预测 ROI 覆盖代理。
5. 三场景 pilot 不替代旧 Table7 的四方法20序列比较。正式 baseline、相同输入与硬件计时、独立真实几何评价需要另行冻结执行。

Phase20F readiness 应结合 E3 最终 Mesh 结果判为 YES/CONDITIONAL/NO；真实尺度和配对实测没有补齐时最多 CONDITIONAL。本阶段完成后停止，不自动进入 Phase20F。
