# 实验一四样本代表集方法覆盖与运行状态

## 数据口径

- 代表样本：`KongQueZhuYu`、`DouBanLv1`、`ChangShouHua2`、`CaoMei1`。
- 帧数：4 个样本 x 5 帧 = 20 帧。
- GT 定义：项目现有 LabelMe GT 前景，即闭合目标 linestrip 的并集。
- 产物根目录：`00-论文优化重构/计算机与电子农业特刊实验工作区/06-实验一四样本代表集/E1_Representative4_PottedPlant_VFM`。

## 主要文件

- `manifest.csv`：四样本 20 帧图像、GT JSON 与 GT mask 索引。
- `gt_shape_summary.csv`：GT 轮廓面积与 bbox 审计。
- `method_masks/`：各方法预测 mask 与运行日志。
- `rap_runs/`：SAM3_P2 与 RAP-FSAM3-v2 本轮真实补跑原始产物。
- `fewshot_runs/`：U-Net 与 DeepLabv3+ lite 四样本 few-shot 训练和预测日志。
- `metrics/summary_metrics.csv` 与 `metrics/frame_metrics.csv`：方法级汇总和逐帧指标。
- `visual_assets/source_data/paper_summary_metrics.csv`：论文表格用精简结果。
- `visual_assets/figure_asset_index.csv`：overlay、error map、contact sheet、指标图与 source data 索引。

## 说明

`SAM_existing` 保留为历史导入参照，不作为实验一主表候选。实验一主表应优先使用 `SAM3_P2` 与 `RAP-FSAM3-v2` 两行来代表基础模型入口和本文最终方法；内部方法族的进一步消融仍归入实验三。
