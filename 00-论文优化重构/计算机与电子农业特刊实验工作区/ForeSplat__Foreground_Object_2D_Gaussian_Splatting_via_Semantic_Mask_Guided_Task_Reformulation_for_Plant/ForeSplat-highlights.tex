\section*{Highlights}

\begin{itemize}
\item RAP-FSAM3 adapts vision foundation models to potted-plant foreground priors.
\item Prompt robustness analysis reveals semantic bias in single-prompt VFM segmentation.
\item ForeSplat converts VFM foreground priors into foreground-object 2DGS optimisation.
\item Foreground RGB supervision reduced the leakage energy ratio from 1.2201 to 0.0190.
\item Virtual plant traits agreed with manual measurements, with \(R^2\) up to 0.988.
\end{itemize}
