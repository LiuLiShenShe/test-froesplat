### Seed PyTorch RNG

Source: https://github.com/pytorch/pytorch/blob/v2.5.1/docs/source/notes/randomness.rst

Seeds the PyTorch random number generator for all devices (CPU and CUDA). This helps ensure that sequences of random numbers generated by PyTorch operations are consistent across runs, contributing to reproducibility.

```python
import torch
torch.manual_seed(0)
```

--------------------------------

### PyTorch CUDA Random Number Generation

Source: https://github.com/pytorch/pytorch/blob/v2.5.1/docs/source/cuda.rst

Functions for managing and seeding the CUDA random number generator (RNG) for reproducible results.

```APIDOC
torch.cuda.manual_seed(seed)
  Sets the seed for the current CUDA device's RNG.

torch.cuda.manual_seed_all(seed)
  Sets the seed for all CUDA devices' RNGs.

torch.cuda.seed()
  Sets the seed for the current CUDA device's RNG to a random value.

torch.cuda.seed_all()
  Sets the seed for all CUDA devices' RNGs to random values.

torch.cuda.initial_seed()
  Returns the initial seed of the current CUDA device's RNG.

torch.cuda.get_rng_state(device=None)
  Returns the current RNG state for a given device.

torch.cuda.set_rng_state(new_state, device=None)
  Sets the RNG state for a given device.

torch.cuda.get_rng_state_all()
  Returns the RNG states for all CUDA devices.

torch.cuda.set_rng_state_all(new_state)
  Sets the RNG states for all CUDA devices.
```

### Seed NumPy RNG

Source: https://github.com/pytorch/pytorch/blob/v2.5.1/docs/source/notes/randomness.rst

Seeds the global NumPy random number generator. This is crucial if your application or libraries use NumPy for random operations. Ensure consistency by seeding the global RNG or specific Generator objects.

```python
import numpy as np
np.random.seed(0)
```

--------------------------------

### Seed Python RNG

Source: https://github.com/pytorch/pytorch/blob/v2.5.1/docs/source/notes/randomness.rst

Seeds the standard Python random number generator. This is necessary for custom operators or parts of your application that rely on Python's built-in `random` module to ensure consistent random number generation.

```python
import random
random.seed(0)
```

--------------------------------

### Control CUDA Convolution Benchmarking

Source: https://github.com/pytorch/pytorch/blob/v2.5.1/docs/source/notes/randomness.rst

Disables cuDNN's automatic convolution algorithm benchmarking to ensure deterministic behavior. While this might reduce performance, it eliminates a source of nondeterminism across runs.

```python
torch.backends.cudnn.benchmark = False
```
