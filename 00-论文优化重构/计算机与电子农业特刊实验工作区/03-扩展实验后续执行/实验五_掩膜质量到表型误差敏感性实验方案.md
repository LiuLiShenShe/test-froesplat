# 实验五：掩膜质量到表型误差敏感性实验方案

## 优先级

扩展实验。该实验用于连接基础视觉模型掩膜质量和农业表型测量误差，适合计算机与电子农业特刊主题。

## 核心问题

视觉基础模型掩膜误差会如何传递到植株高度、冠幅、叶长和叶宽等表型测量？

## 假设

- 株高和冠幅依赖整体几何，可能相对鲁棒。
- 叶长受遮挡和叶片完整性影响。
- 叶宽更依赖边界质量、细结构保留和局部网格质量，因此更容易受掩膜边界误差影响。

## 掩膜来源

| 掩膜来源 | 说明 |
| --- | --- |
| SEEM | 通用可提示分割基线 |
| SAM3 单提示词 | 单一文本提示输出 |
| FSAM3 基线 | 内部方法族中间形态，主要归入实验三；若用于本实验，需补统一下游重建 |
| RAP-FSAM3-v2 | 完整修改后模块 |

可选补充：

- 去掉结构化正负提示的 RAP-FSAM3-v2。
- 去掉重建一致性修正的 RAP-FSAM3-v2。
- 人工腐蚀或膨胀掩膜，用于控制变量敏感性分析。

当前表型汇总结论：

| 性状 | n | MAE | RMSE | MAPE(%) | Bias | R2 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 株高 | 21 | 0.9848 | 1.2073 | 6.9064 | 0.5771 | 0.9878 |
| 冠幅 | 21 | 0.8648 | 0.9880 | 4.5000 | 0.6410 | 0.9879 |
| 叶长 | 63 | 0.5063 | 0.6370 | 7.4491 | 0.3133 | 0.9738 |
| 叶宽 | 63 | 0.4502 | 0.6378 | 9.7256 | 0.3825 | 0.8999 |

解释口径：

- 叶宽 MAPE 最高且 R2 最低，支持“叶宽是边界敏感性状”的判断。
- 该结论来自完整流程的人工-虚拟测量一致性，不能直接写成“某个掩膜模型导致某个表型误差”。
- 若要完成严格实验五，需要让 SEEM、SAM3 单提示词、RAP-FSAM3-v2、人工扰动掩膜等来源分别进入同一 2DGS/网格/测量流程，再比较表型误差。

- 第一轮使用与实验一相同的 6 个代表性样本。
- 如果计算量允许，扩展到所有有人工表型值的样本。
- 每个样本需要人工测量的株高、冠幅、叶长和叶宽。

## 指标

| 指标 | 作用 |
| --- | --- |
| 株高 MAE | 整体高度误差 |
| 冠幅 MAE | 水平冠层误差 |
| 叶长 MAE | 叶片尺度误差 |
| 叶宽 MAE | 边界敏感局部误差 |
| 偏差 | 判断高估或低估 |
| R2 | 与人工测量一致性 |
| MAPE | 相对误差 |

## 敏感性分析

建议分析表型误差与以下掩膜指标的关系：

- HD95。
- 边界 F 分数。
- 细结构丢失程度。
- 外部非黑比例。
- 泄漏能量。
- 面积变异系数。
