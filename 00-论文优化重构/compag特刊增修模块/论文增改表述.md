## 三、你可以在论文中新增的核心贡献表述

现在你的 contribution 可以改成下面这样：

1. **We propose a plant-aware VFM prior adapter** that improves SAM3-based plant foreground extraction through prompt ensemble selection, structure-balanced positive-negative prompting, boundary-preserving residual repair and reconstruction-aware re-prompt detection.

2. **We reformulate 2DGS using VFM-derived plant priors**, injecting masks into sparse-track initialization, foreground RGB supervision, opacity constraints, view weighting and Gaussian pruning, thereby shifting the reconstruction target from full-scene appearance to measurable plant objects.

3. **We evaluate the coupling between VFM mask quality and 3D phenotyping**, showing that segmentation improvements translate into reduced foreground leakage, cleaner meshes and more reliable plant-trait measurements.

这样一改，特刊相关性会非常强。

## 四、你不要做的事情

第一，不建议现在真的去 fine-tune SAM3。你的数据量太小，而且一旦说 fine-tuning，审稿人会追问训练集、验证集、标注量、跨物种泛化、是否过拟合。对于 COMPAG 特刊，**frozen foundation model + agriculture-specific adapter + reconstruction-aware optimization** 已经足够。

第二，不要把 IPENS 的三个模块直接照搬成“我们的创新”。尤其是 SSIM re-prompt 和 morphology repair，本身不难，容易被认为只是工程后处理。你要把它们改造成 ForeSplat 独有的版本：**SSIM + mask stability + SfM geometry feedback**，并证明它影响的是 2DGS foreground-object reconstruction，而不只是 2D mask 好看。

第三，不要再把 F2DMAS 的端到端工程结果作为主线。ForeSplat 的主线必须是：

> VFM prior 如何进入 3D Gaussian reconstruction objective，并最终改善 plant phenotyping。

## 五、最终推荐的新增实验优先级

最小可投稿版本，必须做这 3 个：

1. **VFM 横向对比实验**：SEEM / SAM2 / Grounded-SAM / SAM3 / FSAM3 / RAP-FSAM3。
2. **Prompt 鲁棒性与失败模式实验**：P1-P5 + prompt ensemble。
3. **RAP-FSAM3 模块消融实验**：逐步加 prompt ensemble、SPNP、residual repair、re-prompt、geometry feedback。

增强版，再加这 2 个：

4. **VFM prior 注入 2DGS 位置消融**：input only / init only / loss only / pruning only / full。
5. **VFM mask 对表型误差的敏感性实验**：不同 mask source 对株高、冠幅、叶长、叶宽误差的影响。

最推荐你现在的论文新主线是：

> ForeSplat does not simply use SAM3 as a preprocessing tool. It adapts a vision foundation model into reconstruction-aware plant foreground priors and injects these priors into 2DGS optimization, enabling foreground-object reconstruction for measurable 3D plant phenotyping.

这条线最适合 COMPAG 的“农业基础模型”特刊。
