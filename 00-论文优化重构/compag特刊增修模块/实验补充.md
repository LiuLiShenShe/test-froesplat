## 二、你真正应该新增的实验，不止 2 个，而是 5 组

你提到的两个实验是必须的，但还不够。为了让 COMPAG 特刊认可“你对基础视觉模型做了农业适配”，我建议新增以下 5 组实验。

---

### 实验 1：VFM 横向对比实验

这是必须加的。

对比方法建议：

| 方法                               | 类型                                                                  | 是否文本提示 | 是否视频传播 | 是否农业适配 |
| -------------------------------- | ------------------------------------------------------------------- | ------ | ------ | ------ |
| SEEM                             | promptable segmentation                                             | 是      | 弱      | 否      |
| SAM2                             | image/video segmentation                                            | 点/框    | 是      | 否      |
| Grounded-SAM / GroundingDINO+SAM | open-vocabulary + SAM                                               | 是      | 弱      | 否      |
| SAM3 text-only                   | concept/text segmentation                                           | 是      | 是/可跟踪  | 否      |
| FSAM3-base                       | SAM3 + FFT + PCA                                                    | 是      | 是      | 弱      |
| RAP-FSAM3 / Ours                 | SAM3 + prompt ensemble + SPNP + residual repair + geometry feedback | 是      | 是      | 是      |

评价指标不要只报 F1、mIoU、HD95，还要报下游指标：

| 指标类型               | 指标                                                                 |
| ------------------ | ------------------------------------------------------------------ |
| 2D segmentation    | F1, mIoU, HD95, boundary F-score                                   |
| mask stability     | temporal IoU, area CV, connected components/frame                  |
| reconstruction     | PSNR_fg, SSIM_fg, LPIPS_fg                                         |
| foreground leakage | outside ratio, leakage energy                                      |
| geometry           | Gaussian count, mesh connected components, largest-component ratio |
| phenotyping        | plant height MAE, canopy width MAE, leaf width MAE                 |

你已有 FSAM3 vs SEEM：FSAM3 F1=98.3%、mIoU=97.9%、HD95=41.4 px，SEEM 为 95.1%、94.1%、281.9 px。 现在要把这个扩展成 “VFM family comparison”，否则特刊审稿人会觉得 foundation model 证据太薄。

计算量控制方案：
2D segmentation 指标可以跑全部 20 sequences；下游 2DGS 重建指标可以只选 6 个代表性样本跑，因为每个 VFM 都跑完整 2DGS 代价太高。你要在文中说明这是 representative downstream evaluation。

### 实验 2：Prompt 鲁棒性与失败模式实验

你现在已有 P1-P5，但要把它变成正式实验。建议结构如下：

| Prompt                           | 语义          | 主要风险    | F1 | mIoU | HD95 | temporal IoU | leakage |
| -------------------------------- | ----------- | ------- | -: | ---: | ---: | -----------: | ------: |
| P1 green plant                   | 绿色植物区域      | 绿色背景误分  |    |      |      |              |         |
| P2 entire plant excluding pot    | 整株去花盆       | 默认最佳    |    |      |      |              |         |

| P4 crop seedling                 | 幼苗          | 成熟植株欠分割 |    |      |      |              |         |

这组实验的目的不是证明“某个 prompt 绝对最好”，而是证明：

> 单一 prompt 在农业场景中存在语义偏差，而 prompt ensemble + reconstruction-aware selection 可以降低 VFM 的农业域不稳定性。

这个实验非常关键，因为它能告诉审稿人：

### 实验 5：从 VFM mask 到表型误差的敏感性实验

这个实验很适合 COMPAG，因为它连接基础模型和农业表型结果。

做法：用不同 mask 来源重建同一批样本，然后比较表型误差。

| Mask source    | Plant height MAE | Canopy width MAE | Leaf length MAE | Leaf width MAE | Bias |
| -------------- | ---------------: | ---------------: | --------------: | -------------: | ---: |
| SEEM           |                  |                  |                 |                |      |
| SAM3 text-only |                  |                  |                 |                |      |
| FSAM3-base     |                  |                  |                 |                |      |
| RAP-FSAM3      |                  |                  |                 |                |      |

你原文已经有表型结果：株高、冠幅、叶长、叶宽的 (R^2) 分别为 0.9878、0.9879、0.9738 和 0.8999。 现在要补充的是：**这些表型误差到底对 VFM mask 质量有多敏感。**

特别是叶宽，因为你之前结果里叶宽 (R^2) 最低，MAPE 最高。可以明确写：

> Leaf width is more sensitive to VFM boundary errors than plant height and canopy width.

这会让论文的农业解释更强。
