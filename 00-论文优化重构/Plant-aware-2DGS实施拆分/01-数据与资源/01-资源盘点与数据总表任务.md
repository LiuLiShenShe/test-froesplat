# 资源盘点与数据总表任务

## 1. 当前资源目录初步盘点

从 `/data/fj/F2DMAS` 目录可见，当前资源已覆盖完整 pipeline：

| 目录 | 作用 |
|---|---|
| `原始视频/` | 原始视频输入 |
| `01-FFmepg/` | 视频抽帧结果 |
| `02-FFT/` | FFT 帧质量筛选结果 |
| `02-FFT-COLMAP/` | 筛帧后 COLMAP 相关结果 |
| `03-SAM/` | SAM 分割结果 |
| `03-SEEM/` | SEEM 分割结果 |
| `03-ExG+Otsu/` | 传统植被指数/阈值分割 baseline |
| `03-GT/` | 人工标注或人工测量 GT 相关资源 |
| `04-COLMAP/` | COLMAP sparse/dense 或位姿结果 |
| `05-2DGS-ground/` | 2DGS baseline 或 ground 版本输出 |
| `05-2DGS-new/` | 新版 2DGS 输出 |
| `06-MESH-new/` | mesh 输出 |
| `07-SuGaR-GS/` | SuGaR Gaussian 输出 |
| `07-SuGaR-Mesh/` | SuGaR mesh 输出 |
| `10-Instant-NGP/` | NeRF/Instant-NGP 对比资源 |
| `2d-gaussian-splatting-main/` | 2DGS 代码主体 |
| `sam3-main/`、`sam3/` | SAM3/FSAM3 相关代码或资源 |
| `results_seg_compare/` | 分割对比结果 |

## 4. 样本命名规范

建议统一为：

```text
S01_CaoMei1
S02_CaoMei2
S03_DouBanLv1
...
```

保留原目录名作为 `source_name`，论文和实验表格使用 `sample_id`。

## 5. 必须补齐的信息

每个样本至少补齐：

- 原始帧数：`01-FFmepg/<sample>` 下图片数量。
- FFT 后帧数：`02-FFT/<sample>` 下图片数量。
- COLMAP 注册帧数：从 COLMAP log 或 `images.bin/txt` 读取。
- 是否有 SAM/SEEM/FSAM3 mask。
- 是否有人工 GT。
- 是否已有 2DGS、mesh、SuGaR、Instant-NGP 输出。

## 6. 验收标准

数据总表完成后必须能回答：

- 论文实际使用了多少样本、多少物种、多少场景。
- 哪些样本用于主实验。
- 哪些样本用于 prompt sensitivity。
- 哪些样本用于表型精度验证。
- 哪些样本只能用于可视化，不能用于统计结论。

## 7. COLMAP 状态记录

COLMAP 失败样本、重跑原因、输入策略判断和当前重跑进度记录在：

```text
00-论文优化重构/Plant-aware-2DGS实施拆分/01-数据与资源/03-COLMAP失败排查与重跑记录.md
```

后续更新 COLMAP 结果时，应同步维护该文件，尤其是：

- 哪些样本从 FAIL/WARN 变为 OK。
- 使用的是原图、原图+feature mask，还是 masked/crop 图。
- 是否复制回 `04-COLMAP/<sample>`。
- 是否影响主实验、消融实验和表型验证样本选择。
