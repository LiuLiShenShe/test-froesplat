## 1. 重构目标

原论文标题与叙事偏向：

> F2DMAS: A Deployable Digital Twin Framework for High-Fidelity Plant Phenotyping Across Complex Environments

建议重构为方法型论文：

> Plant-aware 2D Gaussian Splatting for Thin-Leaf 3D Reconstruction and Phenotypic Measurement

备选标题：

> Mask-constrained and Edge-aware 2D Gaussian Splatting for Accurate Plant Phenotyping from Smartphone Images

叙事变化：

| 原论文重点 | 新论文重点 |
|---|---|
| 系统集成、数字孪生、应用流程 | 植物感知约束、Gaussian 优化、薄叶边界修正 |
| FSAM3 + 2DGS + TSDF 的 pipeline | mask loss、pruning score、edge-aware TSDF weight 的方法贡献 |
| 证明流程可用 | 证明每个模块能降低背景干扰、伪影和表型误差 |

## 3. 新方法模块边界

| 模块 | 名称 | 论文角色 | 工程角色 |
|---|---|---|---|
| M1 | H-VQG / PR-IQA Hierarchical View Quality Gate | 分层式植物重建视图质量门控 | Raw Gate 初筛原始帧，Mask Gate 检查分割可靠性，Geometry Gate 检查 COLMAP/SfM 几何可靠性 |
| M2 | FSAM3 Plant Mask Generation | 提供植物 foreground mask prior | 生成可复用 mask、alpha、prompt 记录 |
| M3 | Mask-constrained Gaussian Optimization | 核心方法贡献之一 | 在 2DGS loss 中加入 mask 和 background opacity loss |
| M4 | Topology-aware Gaussian Pruning | 核心方法贡献之一 | 多条件评分删除背景、低贡献和碎片 Gaussian |
| M5 | Edge-aware Thin-leaf Meshing | 最有针对性的薄叶贡献 | 在 TSDF 或 mesh 后处理中降低边界膨胀 |

## 6. M1 升级说明：从 FFT 到 H-VQG / PR-IQA

原方案中的 M1 是 FFT-only frame filtering，优点是简单、快速、可解释，但只能检测 motion blur / defocus blur。

建议升级为：

> **H-VQG: Hierarchical Reconstruction-oriented View Quality Gate**

组成：

```text
Gate 1 Raw-view Gate
  = FFT sharpness + CLIP-IQA + exposure + contrast + entropy

Gate 2 Mask Reliability Gate
  = foreground ratio + component stability + hole ratio + boundary/temporal consistency

Gate 3 Geometry Reliability Gate
  = registration success + matches/inlier ratio + reprojection error + view coverage
```

创新性边界：

- 直接使用 CLIP-IQA 只能算弱创新。
- FFT + CLIP-IQA 融合是中等工程增强。
- 单一 PR-IQA full 打分如果一开始依赖 mask/COLMAP，会有前后依赖倒置风险。
- 面向植物三维重建，把 raw perceptual quality、mask reliability 和 geometry reliability 分阶段门控，并用 downstream reconstruction/phenotype accuracy 验证，才适合作为 Plant-aware 2DGS 的第一个子创新点。

因此后续论文贡献点可改为：

1. H-VQG / PR-IQA hierarchical view quality gate。
2. Mask-constrained 2D Gaussian Optimization。
3. Topology-aware Gaussian Pruning。
4. Edge-aware Thin-leaf Meshing 与四层实验验证。
