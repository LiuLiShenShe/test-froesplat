# 阶段路线图与任务清单

## 使用说明与当前状态

本文件是新版 Plant-aware 2DGS 重构项目的**最终阶段路线图**，用于回答“先做什么、后做什么、每个阶段验收什么”。

## 目标重定义：Foreground-object reconstruction

当前项目主目标已明确调整为：

```text
从原始多视角图像中重建 mask foreground object，而不是重建完整场景。
```

这意味着：

- mask 标为前景的对象就是最终重建对象；对 `KongQueZhuYu` 来说，前景包含叶片、花盆、贴标等 mask 前景区域。
- full-scene 2DGS baseline 仍保留，但主要作为 COLMAP/训练稳定性和背景竞争对照，不再是最终质量主指标。
- 主指标从 full-frame PSNR/SSIM/LPIPS 改为 foreground-object 指标：`PSNR_fg`、`SSIM_fg`、`LPIPS_fg_black_bg`、foreground Gaussian 数量、foreground mesh/表型质量和训练成本。
- COLMAP 位姿仍优先使用原始 RGB 图像，不用 masked/crop 图直接跑位姿；mask 从训练、loss、pruning、导出和评测阶段开始作为核心约束。
- M1 的核心目标不是“挑好看的图”，而是在保持视角覆盖完整性的前提下筛选或加权**最有利于 foreground object 三维重建**的视角集合。


- `02-代码重跑整体流程.md`：按路线图实际跑代码、整理数据、重跑 COLMAP、锁定 baseline 的执行细节。

## 阶段 C：M1/M2 输入先验模块

目标：

- 稳定生成高质量 mask，并筛选最有利于 foreground object 三维重建的视角集合。
- M1 的核心目标是提高 foreground-object 重建质量/效率，而不是单纯提高图像质量分数。当前 `KongQueZhuYu A6+M1/H-VQG hard filtering` 与 `A6+M1-reject-only/raw-mask` 均已证明 retained-list hard filtering 会破坏 foreground-object reconstruction；`A6+M1-soft weighting` 已证明不删视角、只调节 RGB loss 权重可以保持 A6 前景质量。因此后续 M1 不再采用简单删图或 retained-list filtering 作为主候选。

M1 foreground reconstruction gate 方案：

```text
Gate 1 Raw Quality
  过滤严重模糊、过曝/欠曝、低对比和运动拖影帧，保证 SfM 和纹理学习底线。

Gate 2 Foreground Object Quality
  评估 mask foreground ratio、主体完整度、最大连通域、边界复杂度、前景中心偏移、遮挡/截断和 temporal stability。

Gate 3 Geometry and Coverage
  评估 COLMAP 注册、matched points、inlier ratio、reprojection error、相邻视角 baseline、视角覆盖均匀性和 foreground-overlap coverage。

Final Selection
  不是简单 top-K 高分，也不是 retained-list 硬筛：
  优先保留全部可用覆盖视角，在 foreground RGB loss 中对退化视角做 soft view weighting。
  若必须删图，则只删除极端坏帧，并按相机轨迹/视角角度分桶保留 anchor views，避免只留下相近视角。
```
