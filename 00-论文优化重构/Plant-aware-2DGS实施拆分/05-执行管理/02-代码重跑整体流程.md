# 代码重跑整体流程

本文件整理 Plant-aware 2DGS 重构项目的代码重跑顺序。它不是论文 Methods 的写作顺序，而是实际工程执行顺序。

## 0. 目标口径重定义

当前代码重跑目标已明确调整为：

```text
重建 mask foreground object，而不是完整背景场景。
```

因此后续所有实验分成两个口径：

- `full-frame`：保留用于与历史 2DGS baseline 对齐，记录 PSNR/SSIM/LPIPS，但不再作为最终目标。
- `foreground-object`：主口径，只在 mask 前景 object 上评估 `PSNR_fg`、`SSIM_fg`、`LPIPS_fg_black_bg`，并统计 foreground Gaussian、mesh 和表型指标。

直接 masked/RGBA 训练是 foreground-object 的朴素 baseline；`F1_high_precision_foreground` 是当前主候选；E7/E8 full-scene 训练 + foreground export 保留为质量上限和背景竞争对照，但不等同于 foreground-only 方法。

当前阶段判定：

```text
已完成：KongQueZhuYu 单样本 full-scene baseline、E7 后处理对照、F1 foreground-only 主候选 30k 验证。
已完成：XianKeLai1 / CaoMei2 / KongQueZhuYu 的 A6 代表样本扩展，且 XianKeLai1 与 CaoMei2 的 A6+M4 已完成。
已完成：KongQueZhuYu 的 M1-hard / M1-reject-only 负证据，以及 S16/S17 A6+M1-soft weighting 三代表样本正式验证。
已完成：CaoMei2 / XianKeLai1 / KongQueZhuYu 的 A6+M1-soft+M4 组合验证，foreground 质量均接近 A6，outside/leakage 不升，三样本总 Gaussian 数相对 A6 减少 18.03%；该结果是 Ours-full practical compact variant 的三样本正证据，并已完成主样本闭环。
当前进入：M5 mesh/phenotype；S19 已在 `KongQueZhuYu` 与 `XianKeLai1` 的 `A6+M1-soft+M4` 30k 模型上完成 mesh-only 结构与效率评价，包括 standard TSDF、smaller truncation TSDF 和 post-boundary cleanup。
尚未完成：foreground mesh/表型指标、论文级图表。
```

F1 与 E7 的关系：

- `E7_mask_pruning`：full-scene 训练方法。mask 内 PSNR/SSIM/LPIPS 高，但模型仍学习背景，后处理导出的 foreground object 仍有明显背景泄漏。
- `F1_high_precision_foreground`：foreground-only 训练方法。它不是 E7 的改名版本，而是从初始化点云和训练 loss 开始就把目标限定为 mask foreground object。
- 因此论文/实验叙事中，E7 应作为 full-scene 强对照或质量上限，F1 才是当前 foreground-object reconstruction 主线。

命名约定：

- `F1_high_precision_foreground` 是当前代码分支、配置和输出目录名。
- 论文消融表使用 `A0-A6` 表示 foreground-object objective 的逐步构成，避免和历史 `E2/E7/F1` 输出名混淆。
- `A6 = 当前 F1_high_precision_foreground`。

核心原则：

- 先锁定数据、位姿和 baseline，再开发新模块。
- 所有方法必须走同一套训练入口，用开关组合完成消融。
- 默认配置必须严格等价 baseline。
- 新版执行数据统一进入 `/data/fj/F2DMAS/00-论文优化重构/数据管理`。
- COLMAP 位姿阶段优先使用原图或 Gate 1 Raw-view Gate 保留后的原始 RGB 图，不直接使用 masked/crop 图作为输入。
- mask 是最终 foreground-object 定义，主要用于训练前景化、M3 loss、M4 pruning/export、M5 meshing 和 foreground-object eval；COLMAP 位姿仍优先使用原始 RGB。
- M1-hard 与 M1-reject-only/raw-mask 已作为负证据保留：retained-list hard filtering 会破坏 foreground-object reconstruction，不作为当前主方法组件。
- S16/S17 A6+M1-soft weighting 已完成：不删除视角、仅加权 RGB loss 时，foreground-object 指标在三代表样本上接近 A6，并通过 foreground-only 阈值；总 Gaussian 数减少 213139，约 17.52%。

## 1. 总体顺序

推荐重跑顺序：

```text
S0 环境与输出规范
  ↓
S1 数据盘点与样本冻结
  ↓
S2 帧提取与基础质量筛选
  ↓
S3 COLMAP 位姿检查、失败样本重跑与可用相机锁定
  ↓
S4 full-scene 2DGS baseline 与 foreground-object eval
  ↓
S5 M2 FSAM3 mask 生成与对齐
  ↓
S6 M1 foreground reconstruction view-quality gate
  ↓
S7 foreground-object training / M3 Mask-constrained 2DGS
  ↓
S8 foreground-object pruning / export
  ↓
S9 foreground-object meshing
  ↓
S11 foreground-object Gaussian export/eval
  ↓
S10 主实验矩阵、指标汇总与论文图表
```

其中 M1 不是单一前置分数，而是 foreground-object 三维重建视角门控：Gate 1 在 S2 作为原始帧质量底线；Gate 2 在 S5 之后检查 foreground object mask 的完整性、尺度、稳定性；Gate 3 在 S3 之后检查 COLMAP/SfM 几何可靠性和视角覆盖。论文叙事上可以把 M1 放在 Methods 第一个模块，但工程执行上必须按各 gate 所依赖的信息分阶段运行。

## 5. S3：COLMAP 位姿检查、失败样本重跑与相机锁定

这是所有后续 2DGS/3DGS/SuGaR 实验的前置关键步骤。

当前策略：

```text
原图或 Gate 1 保留后的原始 RGB 图 → COLMAP 位姿估计
mask → 后续约束或可选 feature mask，不直接替代 COLMAP 输入图像
```

原因：

- masked/crop 图会丢失背景纹理，历史结果中多个样本只注册 2-3 张。
- 植物叶片弱纹理、重复纹理多，COLMAP 需要足够上下文稳定求位姿。
- 背景点可以后处理过滤，但相机位姿失败会导致后续全部不可用。

## 8. S6：M1 foreground reconstruction view-quality gate

目标：

- 筛选出最有利于 foreground object 三维重建的图像。
- Gate 1 不依赖 mask/COLMAP，过滤严重模糊、曝光失败、低纹理和运动拖影。
- Gate 2 在 FSAM3 后检查 foreground object 是否完整、尺度合适、边界清晰、跨帧稳定。
- Gate 3 在 COLMAP/SfM 后检查几何可靠性和视角覆盖，避免 retained list 视角扎堆。

执行顺序：

```text
M1-F0 no filtering
M1-F1 FFT-only / raw reject-only
M1-F2 Raw + foreground reject-only
M1-F3 hard-gated H-VQG
M1-F4 coverage-balanced selection
M1-F5 soft view weighting
```

foreground reconstruction gate：

```text
Gate 1: Q_raw = blur/FFT + exposure + contrast + entropy + optional CLIP-IQA
Gate 2: Q_fg  = foreground_area_range + largest_component + boundary_sharpness
                + truncation_penalty + center_offset_penalty + temporal_stability
Gate 3: Q_geo = registration + matched_points + inlier_ratio - reprojection_error
                + view_baseline + foreground_overlap_coverage
Final: reject severe degradation + coverage-balanced selection or soft view weighting
```

工程注意：

- M1 只改变进入后续阶段的帧集合或帧权重；hard filtering 作为负对照，最终候选优先使用 coverage-balanced selection 或 view weighting。
- 每层 gate 都要生成 retained/rejected list。
- Gate 1 筛掉帧会改变 SfM 输入集合，因此需要单独跑 COLMAP 或重新确认相机列表。
- Gate 2 发生在 FSAM3 后，不能作为真正第一步。
- Gate 3 发生在 COLMAP 后，不能用于前置抽帧。
- 为公平对比，下游 2DGS 参数保持一致。
- 不能只按总分 top-K；必须按相机轨迹或视角方向分桶，保留视角多样性。
- geometry gate 不能只做 hard delete。除明显异常位姿外，低分视角优先降权而不是删除。
- M1 是否有效以 foreground-object 指标和训练效率判断，不以 full-frame 指标判断。

验收：

- 输出 `raw_quality_scores.csv`、`mask_reliability_scores.csv`、`geometry_reliability_scores.csv`。
- 输出每层 accepted/rejected examples。
- Table 2 能填：retained frames、registered views、sparse points、foreground coverage、azimuth coverage、empty angular bins、min views per bin、PSNR_fg、SSIM_fg、LPIPS_fg、mesh time、trait MAPE。
