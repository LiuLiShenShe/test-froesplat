## Fig. 3：Method Architecture

核心方法图，必须重画。

推荐结构：

```text
Multi-view RGB images
-> H-VQG hierarchical view quality gate
-> FSAM3 mask generation
-> Mask-constrained 2DGS optimization
-> Topology-aware Gaussian pruning
-> Edge-aware TSDF meshing
-> Phenotypic measurement
```

图中必须标注：

- Gate 1: `Q_raw = alpha Q_fft + beta Q_clip + gamma Q_exposure + delta Q_contrast + eta Q_entropy`

- Gate 3: `Q_geo = mu_1 Q_reg + mu_2 Q_match + mu_3 Q_inlier - mu_4 E_reproj + mu_5 Q_coverage`
- `L_rgb`
- `L_mask`
- `L_bg-opacity`
- Gaussian pruning score `S_i`
- edge-aware TSDF weight `w'`
