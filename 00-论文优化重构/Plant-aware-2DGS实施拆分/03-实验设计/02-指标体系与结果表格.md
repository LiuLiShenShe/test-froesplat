# 指标体系与结果表格

## 1. Rendering Fidelity

| 指标 | 方向 | 说明 |
|---|---|---|
| PSNR | up | 像素级重建质量 |
| SSIM | up | 结构相似性 |
| LPIPS | down | 感知相似性 |

注意：

- 渲染指标不能作为唯一结论。
- 植物表型论文必须同时报告几何、效率和表型误差。

## 2. Geometric Quality

| 指标 | 方向 | 说明 |
|---|---|---|
| Chamfer Distance | down | 与参考点云/mesh 的距离 |
| F-score | up | 几何完整性 |
| Normal Consistency | up | 表面法向稳定性 |
| Leaf edge thickness | down | 薄叶片边界膨胀程度 |
| Floating artifact ratio | down | 漂浮点比例 |
| Connected component count | down | 碎片数量 |
| Mesh purity | up | mesh 中植物主体占比 |

如果没有高精度扫描 GT，Chamfer Distance 可替代为：

- 与人工清理后的 mesh 比较。
- 与最佳重建模型 pseudo-GT 比较。
- 与多视角融合 pseudo-GT 比较。

如果仍无法做 Chamfer Distance，必须补充：

- floating artifact ratio
- connected component count
- mesh purity
- leaf edge thickness
- visual comparison

## 3. Efficiency

| 指标 | 方向 |
|---|---|
| training time | down |
| mesh extraction time | down |
| Gaussian number | down |
| GPU memory | down |
| total pipeline time | down |

## 4. Phenotypic Accuracy

| 指标 | 方向 |
|---|---|
| R2 | up |
| MAE | down |
| RMSE | down |
| MAPE | down |
| Bias | close to 0 |
| Bland-Altman limits | narrower |

必须包括：

1. plant height
2. canopy width
3. leaf length
4. leaf width

建议增加：

5. projected area
6. canopy volume
7. leaf inclination angle
8. plant compactness
