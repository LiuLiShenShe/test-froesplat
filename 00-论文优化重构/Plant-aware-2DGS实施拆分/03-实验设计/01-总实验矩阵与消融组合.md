# 总实验矩阵与消融组合

2026-05-20 更新：本文主线已从早期 `E8_full_plant_aware = H-VQG + mask loss + pruning + edge-aware` 调整为 foreground-object reconstruction。当前核心方法为 A6，M4 是安全增强；`M1/H-VQG hard filtering` 已作为负证据保留，不再作为 full method 的默认组件。下表中的 E5-E8 保留为历史 full-scene / 模块组合记录，正式论文主表应以 A6 / A6+M4 / 后续 M1-v2 为准。

## 1. 主实验矩阵

主实验用于支撑论文核心结论：Plant-aware 2DGS 在复杂背景、薄叶片边界和表型测量上优于原始 pipeline 和常见 baseline。

| ID | Method | View quality gate | FSAM3 mask | Mask loss | Pruning | Edge-aware meshing |
|---|---|---|---|---|---|---|
| E0 | COLMAP | - | optional | - | - | - |
| E1 | 3DGS | no | no | no | no | no |
| E2 | 2DGS | no | no | no | no | standard |
| E3 | FSAM3-preprocessed 2DGS | no | yes | no | no | standard |
| E4 | FFT + FSAM3 + 2DGS | FFT-only | yes | no | no | standard |
| E5 | H-VQG + FSAM3 + 2DGS | H-VQG | yes | no | no | standard |
| E6 | Mask-constrained 2DGS | H-VQG | yes | yes | no | standard |
| E7 | Mask-constrained + pruning | H-VQG | yes | yes | yes | standard |
| E8 | Full Plant-aware 2DGS | H-VQG | yes | yes | yes | edge-aware |

论文命名：

- E2：Standard 2DGS
- E3：FSAM3-preprocessed 2DGS
- E5：H-VQG-preprocessed 2DGS
- E6：Mask-constrained 2DGS
- E7：Mask-constrained + topology-aware pruning
- E8：历史 full-scene Plant-aware 组合，不再直接等同于当前 Ours

## 3. 模块消融

这是论文最关键的表之一。必须遵守单分支、可开关、可组合约束。

| Method | M1 View Quality | M2 Mask preprocess | M3 Mask loss | M4 Pruning | M5 Edge meshing |
|---|---|---|---|---|---|
| baseline 2DGS | no | no | no | no | no |
| + FSAM3 | no | yes | no | no | no |
| + FFT | FFT-only | yes | no | no | no |
| + M1-hard | hard-gated H-VQG | yes | no | no | no |
| + mask loss / A6 | no M1 by default | yes | yes | no | no |
| + pruning / A6+M4 | no M1 by default | yes | yes | yes | no |
| full candidate | M1-v2 soft weighting or M1-v3 coverage-balanced | yes | yes | yes | yes |

## 4. M1 视图质量诊断消融

| ID | Filtering method | 关键问题 |
|---|---|---|
| M1-A0 | no filtering | 不筛帧基线 |
| M1-A1 | FFT-only | 原始频域模糊检测是否有效 |
| M1-A2 | FFT + CLIP-IQA | Raw Gate 中低层清晰度和语义感知是否互补 |
| M1-A3 | Raw Gate full | 加入 exposure、contrast、entropy 后是否改善前置初筛 |
| M1-A4 | Raw + Mask Gate | FSAM3 后检查 mask 可靠性是否进一步提升 |
| M1-A5 | hard-gated H-VQG | 强负对照：简单硬筛是否破坏视角覆盖 |
| M1-A6 | reject-only raw/mask retained list | 弱负对照：去掉 geometry gate 后 retained-list 是否仍失败 |
| M1-A7 | soft view weighting | 不删视角、只降低低质量视角 loss 权重是否更稳 |
| M1-A8 | coverage-balanced selection | 若必须删图，质量约束内保证角度 / 轨迹覆盖是否更稳 |

可选外部 IQA baseline：

| Method | 备注 |
|---|---|
| MUSIQ | multi-scale image quality transformer |
| MANIQA | ViT + multi-dimension attention NR-IQA |
| TOPIQ | top-down semantics-to-distortion IQA |
