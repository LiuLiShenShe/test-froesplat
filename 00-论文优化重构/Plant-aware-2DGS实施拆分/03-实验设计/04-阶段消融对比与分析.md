# 阶段消融对比与分析

## 1. 文档目的

本文件用于整理 Plant-aware 2DGS 的阶段消融设计、当前已完成的 `KongQueZhuYu` 单样本结果，以及论文中可采用的解释逻辑。

当前项目主目标已经从 full-scene reconstruction 调整为：

```text
Foreground-object reconstruction: 从多视角图像中重建 mask foreground object，而不是重建完整场景后再裁剪。
```

因此，阶段消融不再只看 full-frame PSNR/SSIM/LPIPS，而是优先看：

| 指标 | 方向 | 作用 |
|---|---:|---|
| `PSNR_fg` | up | mask 前景区域的像素重建质量 |
| `SSIM_fg` | up | mask 前景区域结构一致性 |
| `LPIPS_fg_black_bg` | down | 前景感知质量，背景统一置黑 |
| `outside_nonblack_ratio_mean` | down | mask 外仍被渲染为非黑的比例，衡量背景残留 |
| `leakage_energy_ratio_mean` | down | mask 外能量相对前景能量的泄漏比例 |
| `gaussians_30000` | down | 模型规模和后续 mesh 成本 |

当前 foreground-only 分离阈值暂定为：

```text
outside_nonblack_ratio_mean < 0.05
leakage_energy_ratio_mean < 0.10
```

### 3.3 结果解读

第一，A0 说明 full-scene 2DGS 的 mask 内质量不差，但不是 foreground-only。A0 的 `PSNR_fg=24.2090`，说明模型确实能重建前景区域；但 `outside_nonblack=0.9908`、`leakage=1.2201`，说明 mask 外几乎全是可见背景。这类结果不能满足植物-only 输出。

第二，A1 说明简单 mask/RGBA 前景训练可以让背景干净，但会明显损失前景质量。A1 的泄漏很低，但 `PSNR_fg=20.7291`、`LPIPS=0.0696`，说明直接把输入改成前景图并不足以得到高精度植物重建。

第三，A2-A4 说明只加 alpha mask loss 或 bg opacity loss 不够。它们的前景 PSNR 看起来不错，甚至 A4 达到 `24.8126`，但泄漏仍在 `1.22` 左右。这证明如果 RGB loss 仍在整图监督，模型仍然会被奖励去重建背景；mask/bg regularization 只能作为辅助，不能改变任务目标。

第四，A5 是决定性转折。打开 foreground RGB loss 后，RGB 监督只在 foreground object 内计算，背景不再通过 RGB loss 被奖励。A5 的 `outside_nonblack=0.0294`、`leakage=0.0190`，同时 `PSNR_fg=25.1055`，说明它同时实现了前景分离和高质量。

第五，A6 相比 A5 指标接近，但方法定义更干净。foreground track init 从 COLMAP 3D 点真实 2D track 与 mask 的交集过滤初始点云，避免 full-scene 背景点先进入模型。当前单样本上 A6 未显著超过 A5，说明主要增益来自 foreground objective；但 A6 作为完整方法更有物理含义，也更适合作为论文最终方法。

## 4. E7 与 F1/A6 的关系

| 方法 | 训练目标 | 输出本质 | 当前角色 |
|---|---|---|---|
| E7 mask-constrained + pruning | full-scene reconstruction | full-scene Gaussian，之后尝试 mask/pruning/export | 强对照，说明后处理路线的上限和失败点 |
| F1/A6 foreground-only | foreground-object reconstruction | 训练目标本身就是 foreground object | 当前主方法 |

E7 的失败不在于 mask 内指标低，而在于 full-scene Gaussian 已经学入背景；后处理只能从结果里筛，难以处理遮挡、投影混淆和 mask 内背景投影。F1/A6 的核心变化是从训练目标层面切换任务：前景区域承担 RGB 重建，背景区域主要承担 alpha/opacity 压制。

论文中建议使用如下表述：

```text
Post-hoc mask filtering is insufficient because the full-scene radiance field has already allocated capacity to background structures. We therefore reformulate the optimization target from full-scene image reconstruction to foreground-object reconstruction.
```

中文解释：

```text
后处理筛背景不是等价方案，因为 full-scene 模型在训练时已经把容量分配给背景结构。我们将优化目标从整图重建改写为前景对象重建，使模型从初始化、监督和正则化阶段都围绕 foreground object 收敛。
```

## 5. M1/M2 输入先验消融设计

M1/M2 不应被写成“图像质量筛选”本身，而应写成 reconstruction-effective foreground prior。

2026-05-20 更新：现有 `KongQueZhuYu A6+M1/H-VQG hard filtering` 与 `A6+M1-reject-only/raw-mask` 均已完成，结果均为负证据。它们不是证明 M1 方向错误，而是证明 retained-list hard filtering / 硬删视角不是可靠 M1。植物 foreground-object reconstruction 需要同时保留质量、视角覆盖和训练/评估分布稳定性，不能只删低分图。

2026-05-21 更新：`A6+M1-soft weighting` 已完成 30k 训练、渲染和 foreground-object eval。结果显示，在不删除视角、仅对 RGB reconstruction loss 进行软权重调节时，S16 基本保持 A6 前景质量，并通过 foreground-only 分离阈值。这说明 M1 的合理方向不是 retained-list hard filtering，而是在保持多视角覆盖前提下调节视角贡献。

2026-05-21 追加：S17 已将 M1-soft 扩展到 `XianKeLai1` 和 `CaoMei2`。三代表样本均显示：M1-soft 基本保持 A6 foreground-object quality，同时略降 outside/leakage，并减少 Gaussian 数量。因此 M1-soft 已从单样本正证据升级为跨样本正证据，可作为 `Ours-full` 候选模块；下一步重点是与 M4 组合验证。

| ID | 输入策略 | Raw quality | Foreground quality | Geometry/coverage | 评价指标 | 目的 |
|---|---|---:|---:|---:|---|---|
| M1-A0 | no filtering | no | no | no | foreground metrics + time | 不筛帧基线 |
| M1-A1 | FFT-only | yes | no | no | foreground metrics + registered views | 频域模糊检测是否足够 |
| M1-A2 | Raw Gate full | yes | no | no | foreground metrics + sparse points | raw 清晰度/曝光/对比度是否有用 |
| M1-A3 | Raw + Mask Gate | yes | yes | no | foreground metrics + mask coverage | foreground 完整性和 mask 可靠性是否改善训练 |
| M1-A4 | hard-gated H-VQG | yes | yes | hard delete | foreground metrics + coverage | 负对照：证明简单硬筛会破坏 coverage |
| M1-A5 | reject-only severe degradation | yes | yes | conservative | foreground metrics + train time | 只删除严重坏帧，避免误删覆盖视角 |
| M1-A6 | coverage-balanced selection | yes | yes | yes | foreground metrics + view diversity | 在角度覆盖约束内优先选高质量视角 |
| M1-A7 | soft view weighting | yes | yes | weighted | foreground metrics + train time | 不删视角，只降低低质量视角 loss 权重 |

建议固定下游方法为 A6，然后只改变输入视角集合：

```text
M1 variant -> same COLMAP source policy -> same A6 foreground-only training -> same foreground-object eval
```

这样能回答：更好的输入先验是否提升 A6 的稳定性、效率和跨样本表现。

### 5.1 M1 retained-list 负证据：硬筛式视角选择消融分析

结果来源：

```text
数据管理/05-评测结果/S14_M1_on_A6/kongquezhu_A6_vs_A6_HVQG_summary.md
```

| Version | PSNR_fg | SSIM_fg | LPIPS_fg | Outside | Leakage | Gaussians |
|---|---:|---:|---:|---:|---:|---:|
| A6 | 25.0072 | 0.8548 | 0.0438 | 0.0294 | 0.0189 | 591623 |
| A6+M1/H-VQG hard filtering | 12.5478 | 0.6018 | 0.1179 | 0.1743 | 0.3020 | 597116 |
| A6+M1-reject-only/raw-mask | 13.4557 | 0.6244 | 0.1115 | 0.1450 | 0.2848 | 579612 |

这组结果说明，当前 retained-list hard filtering 版本不能作为有效 M1。与 A6 相比，包含 geometry gate 的 M1-hard 将 `PSNR_fg` 从 `25.0072` 降到 `12.5478`，`leakage` 从 `0.0189` 升到 `0.3020`；关闭 geometry hard delete 后，M1-reject-only/raw-mask 只恢复到 `PSNR_fg=13.4557`、`leakage=0.2848`，仍明显超过 foreground-only 分离阈值。

这不是 M1 方向错误，而是说明：

- 高分图不等于好重建图；
- 被删除视角可能承担侧面、背面、顶部或遮挡补充信息；
- 失败不只来自 geometry gate 过强，raw/mask retained list 本身也可能破坏训练视角集合和评估视角分布；
- geometry gate 不能只做 hard delete，否则会进一步破坏 coverage completeness；
- M1 不能作为当前主方法的一部分，当前主方法仍是 A6；
- M1-hard 与 M1-reject-only/raw-mask 应作为负对照保留，用于说明下一版 M1 必须改成 soft weighting 或真正 coverage-balanced anchor-view selection。

论文中建议将本节写为 `Effect of hard-gated view selection` / `硬筛式视角选择消融分析`。核心表述是：当前 M1 retained-list 筛选策略在 KongQueZhuYu 上产生负结果，无论使用 hard geometry gate 还是 reject-only/raw-mask 策略，均明显破坏 foreground-object reconstruction。这说明植物前景对象重建依赖完整多视角覆盖，M1 后续应从 hard filtering 转向 soft view weighting 或 coverage-balanced view selection。

```text

```


```text
Soft view weighting preserves multi-view coverage and avoids the failure of hard retained-list filtering. This result suggests that view quality should regulate gradient contribution rather than remove views from foreground-object 2DGS training.
```

中文解释：

```text
软权重策略保留了多视角覆盖，避免了硬筛视角造成的重建失败。这说明视图质量更适合作为训练贡献权重，而不是用于直接删除视角。
```

### 5.3 下一版 M1 方向

2026-05-20 追加：S15 已补 `A6+M1-reject-only/raw-mask`。该分支关闭 geometry hard delete，仅复用 raw/mask retained list，保留 24 个 test views。结果相对 M1-hard 有轻微恢复，但仍远低于 A6：`PSNR_fg=13.4557`、`SSIM_fg=0.6244`、`LPIPS_fg=0.1115`、`outside=0.1450`、`leakage=0.2848`、`Gaussians=579612`。这说明失败不只来自 geometry hard delete；现有 raw/mask retained-list hard filtering 也会破坏 foreground-object reconstruction。因此后续不应继续沿 retained-list hard filtering 微调，而应优先实现 soft view weighting，其次实现真正 coverage-balanced anchor-view selection。

2026-05-21 追加：S16/S17 已补 `A6+M1-soft weighting`。该分支不删除训练/测试视角，仅对 foreground RGB loss 加权，在三代表样本上结果均接近 A6 并通过 foreground-only 阈值。因此，后续 M1 的优先级应从“是否继续筛图”调整为“如何校准 soft weight”和“如何与 M4 组合”：例如限制权重动态范围、按 pose/bin 做权重归一化，或结合 coverage-aware normalization。

后续 M1 不再定义为简单 H-VQG hard filtering，而改为三个候选方向：

| Candidate | Strategy | Expected role |
|---|---|---|
| M1-v1 reject-only severe degradation | 只删除严重模糊、曝光失败、mask 完全错误或 COLMAP 明显异常视角 | S15 raw/mask retained-list 仍失败，需改成真正极端坏帧删除，不做激进筛选 |
| M1-v2 soft view weighting | 不删图，在训练 loss 中用视角质量分数降低低质量视角权重 | S16/S17 已验证可跨样本保持 A6 质量、降低 leakage/outside 并减少 Gaussian，是当前最优先主候选 |
| M1-v3 coverage-balanced selection | 先按相机 azimuth / 图像序号 / 轨迹分桶保证覆盖，再在桶内选高质量视角 | 若必须删图，必须先保覆盖，再谈质量 |

下一版 M1 必须额外报告 coverage 指标：

| Metric | Meaning |
|---|---|
| retained views | 保留视角数量 |
| azimuth coverage | 保留视角覆盖角度范围 |
| empty angular bins | 空缺角度区间数量 |
| min views per bin | 每个区间最少视角数 |
| pose graph connectivity | COLMAP 视角连接是否断裂 |

## 6. M4 pruning/export 消融设计

M4 应放在 A6 之后作为实用增强，不建议作为 foreground-only 的核心证明。核心证明已经由 A0-A6 完成。

| ID | Pruning/export strategy | 输入模型 | 评价指标 | 目的 |
|---|---|---|---|---|
| M4-A0 | none | A6 | Gaussians, leakage, mesh time | 不剪枝基线 |
| M4-A1 | opacity-only | A6 | Gaussians, PSNR_fg, leakage | 单纯低 opacity 剪枝是否伤前景 |
| M4-A2 | mask consistency | A6 | leakage, outside nonblack | mask 投票能否进一步减少外泄 |
| M4-A3 | topology-aware pruning | A6 | floating artifact, components, mesh purity | 多条件剪枝是否减少漂浮点 |
| M4-A4 | visibility-aware foreground export | A6 | exported PLY purity, mesh time | 导出 plant-only 资产 |

论文分析重点：

- 如果 M4 降低 Gaussian 数和 mesh time，同时 `PSNR_fg/LPIPS_fg` 基本不变，则说明它是效率和几何清洁度增强。
- 如果 M4 明显降低 leakage，但前景质量下降，需要讨论 clean/quality trade-off。
- M4 不应替代 A5/A6 的 foreground RGB objective，因为 A2-A4 已证明 regularization/post-filter 不能单独解决背景学习。

## 8. 论文故事线

推荐主故事：

1. 原始 2DGS 是 full-scene reconstruction。对植物表型任务来说，full-scene 模型会把背景也重建出来，导致 plant-only asset、mesh 和表型测量受污染。
2. 简单 mask preprocessing 可以让背景干净，但会损失前景纹理和几何质量，不能作为高精度方案。
3. 只加 alpha mask loss 或 background opacity loss 不能解决问题，因为整图 RGB loss 仍然奖励背景重建。
4. 我们把监督目标改成 foreground-object objective：RGB 只在 foreground mask 内优化，背景主要通过 alpha/mask 和 opacity 约束压低。
5. 进一步用 COLMAP track 与 mask 的交集过滤初始化点云，使初始几何就偏向前景对象，而不是先学 full-scene 再筛。
6. 在此基础上，M1 提供 reconstruction-effective views，M4 提供更干净的 Gaussian/export，M5 提供 phenotype-ready mesh。

一句话创新表述：

```text
The key innovation is not mask-based post-processing, but reformulating 2D Gaussian Splatting from full-scene reconstruction into mask-defined foreground-object reconstruction, supported by track-aware foreground initialization and foreground-specific optimization losses.
```
