# M1-M5 开关式代码接入记录

更新日期：2026-05-18

## 开发原则

本轮修改遵守新版开发约束：

- 默认命令仍严格运行 baseline。
- 所有新增模块必须通过 `--xxx` 参数显式启用。
- 不传新参数时不要求 mask、不执行 pruning、不改变 standard meshing。
- 先用 `KongQueZhuYu` 单场景 smoke 验证，确认有效后再扩展到代表样本和全场景。

## 已接入内容

### M1 H-VQG 接口

已加入参数：

```text
--view_quality_mode
--raw_gate_mode
--mask_gate_mode
--geo_gate_mode
--raw_gate_list
--mask_gate_list
--geo_gate_list
```

当前实现：

- 支持读取 txt/csv/json 的 retained frame list。
- 在 `Scene` 构建阶段按 image stem 过滤 train/test cameras。
- `run_hvqg.py` 已支持三层 gate 的 threshold 与 keep-ratio 参数，可用于保守 smoke 和阈值扫描。
- 默认 `none`，不改变 baseline。

说明：

- 当前已实现 FFT/exposure/contrast/entropy、mask reliability、COLMAP registration/matches 的 V1 打分。
- CLIP-IQA、逐图 reprojection error、view coverage 仍待补强。

### M2 Mask 输入

已加入参数：

```text
--mask_mode {none,preprocess,alpha}
--mask_dir
--mask_pattern
--mask_threshold
```

当前实现：

- `mask_mode=none`：baseline，不读取 mask。
- `mask_mode=alpha`：读取 mask 并保存到 `Camera.gt_alpha_mask`，RGB 图不变。
- `mask_mode=preprocess`：读取 mask，并将训练 RGB 乘以 mask。

默认 `none`。

### M3 Mask-constrained Loss

已加入参数：

```text
--use_mask_loss
--use_bg_opacity_loss
--lambda_mask
--lambda_bg
--mask_loss_type {l1,bce,dice,l1_dice}
--mask_ignore_boundary_px
--mask_loss_start_iter
--mask_loss_warmup_iters
```

当前实现：

- 使用 renderer 已有的 `rend_alpha`。
- 支持 mask consistency loss。
- 支持 background opacity loss。
- 支持 boundary ignore band。
- 支持 warm-up。
- 缺少 mask 时给出明确错误，不静默跳过。

默认关闭，`lambda_mask=0.0`、`lambda_bg=0.0`。

### M4 Pruning

已加入参数：

```text
--pruning_mode {none,opacity,brightness,mask,topology}
--pruning_start_iter
--pruning_interval
--pruning_opacity_threshold
--pruning_brightness_threshold
--pruning_mask_threshold
--pruning_mask_max_views
--pruning_max_remove_ratio
--pruning_mask_score_weight
--save_pruning_report
```

当前实现：

- `opacity`：按 opacity 阈值剪枝。
- `brightness`：按 DC color brightness 阈值剪枝。
- `mask`：将 Gaussian 投影到多视角 mask，按 mask consistency 剪枝。
- `topology`：组合 opacity、brightness、mask consistency。
- `pruning_max_remove_ratio` 限制单次最大删除比例，避免误删主体。
- pruning 已移动到 optimizer step 之后执行。
- mask consistency 已进入限额排序，避免 `topology` 模式只按 brightness/opacity 选择删除点。
- 若保存迭代同时触发 pruning，会在 pruning 后重新保存同一 iteration 点云。

默认 `none`。

### M5 Meshing Mode

已加入参数：

```text
--meshing_mode {standard,small_trunc,edge_aware,post_boundary}
--edge_truncation_scale
--boundary_shrink_ratio
```

当前实现：

- `standard`：原始 TSDF。
- `small_trunc` / `edge_aware`：先以更小 `sdf_trunc` 作为可运行占位验证。
- `post_boundary`：将 mesh vertices 投影到多视角 mask，按 silhouette consistency 做保守内缩修正。
- render 后输出 `mesh_metrics.json`，记录 raw/post mesh 顶点面数、使用 mask 数、投影外点比例和收缩幅度。

默认 `standard`。
