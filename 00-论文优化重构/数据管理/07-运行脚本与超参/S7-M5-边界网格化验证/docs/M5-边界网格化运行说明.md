# M5 边界网格化运行说明

更新日期：2026-05-18

## 目标

将 `M5` 从仅有参数接口的占位状态，推进到第一版真实可运行的边界约束 mesh 后处理。

当前实现方式：

- 先走标准 TSDF 重建；
- 再在 `post_boundary` 模式下，把 mesh 顶点投影到多视角 foreground mask；
- 对跨视角 foreground 一致性较低的边界区域做保守内缩。

## 当前参数

```text
--meshing_mode post_boundary
--boundary_shrink_ratio <float>
--mask_dir <path>
--mask_pattern mask_{stem}.png
```

## 当前实现特点

- 不改 baseline 默认 `standard` 路径；
- 只有在显式指定 `post_boundary` 时才启用；
- 使用多视角 mask 投影一致性做 conservative shrink；
- 当前版本优先保证可运行和方向正确，不追求一次到位的最优边界精度。

## 风险说明

- 过强 shrink 可能让叶宽偏小；
- 如果 mask 边界本身不稳，会把误差传递到 mesh；
- 当前实现仍属于 M5 的 V1，后续可继续升级到 edge-aware TSDF / distance-transform weighting。
