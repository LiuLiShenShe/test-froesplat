## 使用方法

### 方式 1: Python 脚本（推荐）

```bash
# 激活虚拟环境
source /data/fj/instant-ngp/venv/bin/activate

# 训练 NeRF 模型
python scripts/run.py --scene data/nerf/fox --n_steps 1000

# 保存快照
python scripts/run.py --scene data/nerf/fox --save_snapshot fox_trained.msgpack

# 测试渲染质量
python scripts/run.py --scene data/nerf/fox --test_transforms data/nerf/fox/transforms.json
```

### 方式 2: 命令行（无GUI）

```bash
# 基本训练
./build/instant-ngp data/nerf/fox --no-gui

# 加载预训练模型
./build/instant-ngp data/nerf/fox --snapshot fox_trained.msgpack --no-gui
```

### 方式 3: Python API

```python
import sys
sys.path.insert(0, 'build')
import pyngp as ngp

# 创建 testbed
testbed = ngp.Testbed(ngp.TestbedMode.Nerf)

# 加载数据
testbed.load_training_data('data/nerf/fox')

# 训练
for i in range(1000):
    testbed.train()

# 保存模型
testbed.save_snapshot('model.msgpack')
```

## 故障排除

### 问题: CUDA 内存不足
**解决方案**: 减小 `aabb_scale` 参数或使用较小的批次大小

### 问题: 训练不收敛
**解决方案**:
1. 检查输入图像质量（避免模糊）
2. 调整 `aabb_scale` 参数
3. 确保相机姿态正确

### 问题: Python 导入错误
**解决方案**:
```bash
source venv/bin/activate
export PYTHONPATH=$PYTHONPATH:$(pwd)/build
```
