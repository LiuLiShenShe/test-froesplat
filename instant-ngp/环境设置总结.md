## 待完成任务

### 1. 安装 CMake
```bash
sudo apt-get update
sudo apt-get install cmake
```
要求: CMake 3.21 或更高版本

### 2. 安装其他依赖库 (Linux)
```bash
sudo apt-get install build-essential git python3-dev python3-pip \
    libopenexr-dev libxi-dev libglfw3-dev libglew-dev libomp-dev \
    libxinerama-dev libxcursor-dev
```

### 3. 编译项目
```bash
cd /data/fj/instant-ngp
cmake . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build --config RelWithDebInfo -j
```

### 4. 测试运行
编译成功后,可以运行:

#### 方式1: 使用可执行文件
```bash
./instant-ngp data/nerf/fox
```

#### 方式2: 使用 Python 绑定
```bash
source venv/bin/activate
python scripts/run.py --scene data/nerf/fox
```

#### 方式3: 运行 Jupyter Notebook
```bash
jupyter notebook notebooks/instant_ngp.ipynb
```

## 注意事项
1. 此项目需要 NVIDIA GPU 和 CUDA 支持
2. Tensor Cores 可以提高性能 (RTX 系列显卡)
3. 编译可能需要较长时间 (约1小时)
4. 如果编译时内存不足,去掉 `-j` 选项

## 快速开始命令
```bash
# 激活虚拟环境
source /data/fj/instant-ngp/venv/bin/activate

# 测试环境
cd /data/fj/instant-ngp
python test_environment.py

# 编译项目 (安装 CMake 后)
cmake . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build --config RelWithDebInfo -j

# 运行示例
./instant-ngp data/nerf/fox
```
