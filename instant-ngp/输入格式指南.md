# Instant-NGP 输入格式指南

## 图像格式支持

### ✅ 支持的格式

| 格式 | 扩展名 | RGB | RGBA | 说明 |
|------|--------|-----|------|------|
| PNG  | .png   | ✓   | ✓    | **推荐用于 RGBA** |
| JPEG | .jpg, .jpeg | ✓ | ✗  | 推荐用于 RGB 照片 |
| EXR  | .exr   | ✓   | ✓    | HDR 图像，支持浮点精度 |
| BMP  | .bmp   | ✓   | ✓    | Windows 位图 |
| GIF  | .gif   | ✓   | ✓    | 支持透明度 |
| TGA  | .tga   | ✓   | ✓    | Targa 格式 |
| PIC  | .pic   | ✓   | -    | Softimage PIC |
| PNM  | .pnm   | ✓   | -    | Portable Any Map |
| PSD  | .psd   | ✓   | -    | Photoshop 文档 |

## RGBA PNG 支持详解

### ✅ 完全支持 RGBA PNG！

Instant-NGP 完全支持带 Alpha 通道的 PNG 图像。

### Alpha 通道的用途

1. **背景透明**
   - 透明像素（alpha=0）不参与损失计算
   - 帮助模型忽略背景干扰

2. **前景/背景分离**
   - 聚焦于主要对象
   - 提高重建质量

3. **动态对象移除**
   - 移除照片中的移动物体（行人、车辆等）
   - 也可以使用 `dynamic_mask_XXX.png` 文件

### 使用方式

#### 方式 1: 直接使用 RGBA PNG

```python
# 使用 PIL 创建 RGBA PNG
from PIL import Image
import numpy as np

# 创建 RGBA 图像
img = np.zeros((H, W, 4), dtype=np.uint8)
img[:, :, :3] = rgb_data  # RGB 通道
img[:, :, 3] = alpha_data  # Alpha 通道

# 保存
Image.fromarray(img, 'RGBA').save('image.png')
```

#### 方式 2: RGB 图像 + 单独的 Alpha 文件

如果已有 RGB 图像，可以提供单独的 alpha 文件：

```
images/
├── 0001.png          # RGB 图像
├── 0001.alpha.png    # Alpha 通道（灰度图）
├── 0002.png
├── 0002.alpha.png
...
```

**命名规则**: `原文件名.alpha.扩展名`

**Alpha 文件要求**:
- 灰度图像（红通道会被使用）
- 与原图相同分辨率
- 白色 = 不透明，黑色 = 透明

## transforms.json 格式

### 基本结构

```json
{
  "camera_angle_x": 0.748184,
  "camera_angle_y": 1.219357,
  "aabb_scale": 4,

  "frames": [
    {
      "file_path": "images/0001.png",
      "transform_matrix": [
        [r00, r01, r02, t0],
        [r10, r11, r12, t1],
        [r20, r21, r22, t2],
        [0.0, 0.0, 0.0, 1.0]
      ]
    },
    // ... 更多帧
  ]
}
```

### 关键参数

#### 必需参数
- `camera_angle_x`: 水平视场角（弧度）
- `frames`: 帧列表，每帧包含 `file_path` 和 `transform_matrix`

#### 可选参数
- `aabb_scale`: 场景边界框大小 (1, 2, 4, 8, 16, 32, 64, 128)
  - 小物体/合成场景: 1
  - 室内场景: 4-16
  - 室外大场景: 32-128
- `scale`: 缩放因子（默认 0.33）
- `offset`: 偏移量（默认 [0.5, 0.5, 0.5]）
- `fl_x`, `fl_y`: 焦距（可选，优先级高于 camera_angle）
- `k1`, `k2`: 径向畸变系数
- `cx`, `cy`: 主点位置

## 数据准备流程

### 使用 COLMAP（推荐）

```bash
# 从视频
python scripts/colmap2nerf.py \
  --video_in video.mp4 \
  --video_fps 2 \
  --run_colmap \
  --aabb_scale 32

# 从图像文件夹
python scripts/colmap2nerf.py \
  --colmap_matcher exhaustive \
  --run_colmap \
  --aabb_scale 32
```

### 手动创建数据集

1. **准备图像**
   - 放在 `images/` 子目录
   - 推荐分辨率: 1000-2000 像素
   - 推荐数量: 50-150 张
   - 支持 RGBA PNG

2. **运行 COLMAP**
   ```bash
   colmap automatic_reconstructor \
     --workspace_path . \
     --image_path images
   ```

3. **转换为 transforms.json**
   ```bash
   python scripts/colmap2nerf.py \
     --colmap_model sparse/0 \
     --aabb_scale 32
   ```

## 图像质量建议

### ✅ 好的数据
- 避免运动模糊
- 避免景深模糊
- 良好的曝光
- 静态场景
- 覆盖完整的视角

### ❌ 避免的问题
- 模糊的图像
- 移动的对象
- 镜头反光
- 过暗/过曝
- 不准确的相机位姿

## Alpha/掩码的使用场景

### 1. 绿幕/蓝幕抠图
```python
# 使用 RGBA PNG 存储抠图结果
rgba_image = remove_green_screen(photo)
rgba_image.save('frame_0001.png')  # PNG with alpha
```

### 2. 移除动态对象
```python
# 方法 1: 直接在 RGBA PNG 中设置 alpha=0
img = Image.open('photo.jpg')
mask = detect_person(img)  # 检测人物
rgba = img.convert('RGBA')
rgba[:, :, 3] = ~mask  # 人物区域设为透明
rgba.save('photo_masked.png')

# 方法 2: 使用单独的掩码文件
# 保存为 dynamic_mask_0001.png
```

### 3. 背景透明化
```python
# 移除背景，保留前景物体
from rembg import remove
img = Image.open('object.jpg')
img_no_bg = remove(img)  # 自动移除背景
img_no_bg.save('object_rgba.png')  # 保存为 RGBA PNG
```

## 常见问题

**Q: RGBA PNG 会增加文件大小吗？**
A: 是的，但 PNG 压缩效果好。对于照片，可以考虑 JPG + 单独的 alpha 文件。

**Q: Alpha 通道精度如何？**
A: 8位（0-255），足够大多数应用。

**Q: 可以使用半透明吗？**
A: 可以，但 instant-ngp 主要使用二值化 alpha（0 或 255）。

**Q: EXR 格式支持 Alpha 吗？**
A: 支持，且支持浮点精度 alpha。

## 总结

✅ **Instant-NGP 完全支持 RGBA PNG 格式**
- 直接使用带 alpha 通道的 PNG
- 或使用 RGB + 单独的 alpha 文件
- 透明像素不参与训练
- 提高前景对象的重建质量
