- 如果 point cloud 的 bias/MAPE 明显更低：说明 TSDF meshing / Marching Cubes 边界膨胀是主要误差来源之一。
- 如果 point cloud 也没有明显改善：说明误差更可能已经在 upstream 阶段形成，例如分割边界、2DGS 深度不稳定、斜视角下叶缘几何不足。

Leaf width was then calculated as the maximum distance perpendicular to the leaf-length direction in the selected local point set.
