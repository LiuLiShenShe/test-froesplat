# R1.2 Table 6 消融实验方案

目标：回应审稿人 1 关于 Table 6 的两个问题：

1. 如果 standard 2DGS 和 F2DMAS 都使用含模糊帧的输入，F2DMAS 是否仍然领先？
2. `Plant Seg.` 的提升到底来自 SAM3 本身，还是来自 FSAM3 的附加组件，例如最大连通域/最大聚类筛选、时序一致性、形态学后处理等？

## 推荐主文 Table 6

建议把原来的 `Base / Base+FFT / Base+SAM3 / F2DMAS` 改成下面这种命名。核心是固定重建后端都是 2DGS，只改变输入前处理。

```text
Table 6. Ablation study of F2DMAS using the same 2DGS reconstruction backend.

| Method | Input frames | Background handling | FFT blur-frame filtering | Foreground module | 2DGS | PSNR↑ | SSIM↑ | LPIPS↓ | Training Time/s↓ | Mesh Time/s↓ |

| Baseline + FSAM3 / F2DMAS w/o FFT | Raw frames with blurred frames | FSAM3 foreground masks | × | SAM3 + FSAM3 post-processing | ✓ | [run] | [run] | [run] | [run] | [run] |
```

如果你原表里的 `Base+SAM3` 实际上已经用了完整 FSAM3，而不是 SAM3-only，那么它应改名为：

```text
Baseline + FSAM3 / F2DMAS w/o FFT
```

然后新增真正的：

```text
Baseline + SAM3
```

如果你原表里的 `Base+SAM3` 只是 SAM3-only，则保留为 `Baseline + SAM3`，再新增 `Baseline + FSAM3 / F2DMAS w/o FFT`。

## 每一行具体怎么跑

### 1. Baseline

目的：标准 2DGS 基线。

输入：

- 原始抽帧图像。
- 保留背景。
- 保留模糊帧。
- 不做 FFT 过滤。
- 不做 SAM3/FSAM3 前景分割。

流程：

```text
raw frames with background
-> SfM/COLMAP
-> 2DGS
-> TSDF mesh
-> PSNR / SSIM / LPIPS / training time / mesh time
```

这就是你现在的 Base。

### 2. Baseline + FFT

目的：回答“standard 2DGS 如果也去掉模糊帧会怎样”。

输入：

- 先对原始抽帧做 FFT blur-frame filtering。
- 只删除严重模糊帧。
- 仍然保留背景。
- 不做 SAM3/FSAM3 前景分割。

流程：

```text
raw frames with background
-> FFT blur-frame filtering
-> filtered frames with background
-> SfM/COLMAP
-> 2DGS
-> TSDF mesh
-> metrics
```

这就是你现在的 Base+FFT。

### 3. Baseline + SAM3

目的：回答“提升是不是只来自 SAM3”。

输入：

- 原始抽帧图像。
- 保留模糊帧。
- 用 SAM3 直接生成前景 mask。
- 不使用 FSAM3 的最大连通域/最大聚类筛选。
- 不使用 FSAM3 的形态学闭运算或边界修复。
- 不使用额外的时序一致性后处理，除非这属于 SAM3 本身默认输出。

流程：

```text
raw frames with blurred frames
-> SAM3-only plant mask
-> foreground images
-> SfM/COLMAP
-> 2DGS
-> TSDF mesh
-> metrics
```

注意：这一行很重要。SAM3-only 可能出现粘连、背景误分割、小碎片、盆/支架残留等问题。不要人为修 mask，否则就不是 SAM3-only 了。

### 4. Baseline + FSAM3 / F2DMAS w/o FFT

目的：回答审稿人说的“如果 base 和 ours 都使用含模糊帧输入，会怎样”。这就是完整方法去掉 FFT。

输入：

- 原始抽帧图像。
- 保留模糊帧。
- 使用完整 FSAM3 前景提取。
- 不做 FFT blur-frame filtering。

FSAM3 应包含你真实方法中的组件，例如：

- SAM3 prompt-based plant mask。
- 时序传播或多视角一致性。
- 最大连通域/最大聚类筛选。
- 形态学闭运算。
- 小碎片去除。
- Alpha foreground image generation。

流程：

```text
raw frames with blurred frames
-> FSAM3 foreground extraction
-> foreground images
-> SfM/COLMAP
-> 2DGS
-> TSDF mesh
-> metrics
```

这一行可以命名为：

```text
Baseline + FSAM3
```

或者：

```text
F2DMAS w/o FFT
```

主文表格里建议写成：

```text
Baseline + FSAM3 / F2DMAS w/o FFT
```

审稿人一眼就能看懂。

### 5. F2DMAS

目的：完整方法。

输入：

- 原始抽帧图像。
- 先做 FFT blur-frame filtering。
- 对过滤后的帧做 FSAM3 前景提取。

流程：

```text
raw frames
-> FFT blur-frame filtering
-> FSAM3 foreground extraction
-> foreground images
-> SfM/COLMAP
-> 2DGS
-> TSDF mesh
-> metrics
```

这是完整 F2DMAS。

## 实验控制条件

所有行必须保持一致：

- 同一批样本。
- 同一抽帧策略。
- 同一图像分辨率。
- 同一 2DGS 参数，包括迭代次数、学习率、densification 设置、随机种子。
- 同一 TSDF voxel size、truncation distance、Marching Cubes 设置。
- 同一硬件环境。
- 同一计时方式。
- 同一测试视角和评价协议。

建议指标：

- `PSNR`
- `SSIM`
- `LPIPS`
- `Training Time/s`
- `Mesh Time/s`

如果有样本失败，不要直接删掉。记录：

- 成功样本数。
- SfM 注册视角数。
- 是否有明显粘连或背景残留。

## 预期解释逻辑

跑完后按下面关系解释：

### Baseline vs Baseline + FFT

回答：

```text
FFT 去模糊帧本身是否能改善 standard 2DGS。
```

如果提升很小，可以说：

```text
Blur-frame filtering improves input stability to some extent, but background regions still participate in 2DGS optimization and TSDF meshing.
```

### Baseline vs Baseline + FSAM3 / F2DMAS w/o FFT

回答审稿人的核心问题：

```text
在 base 和 ours 都使用含模糊帧输入时，FSAM3 去背景后的方法是否仍然优于 standard 2DGS。
```

如果这一行比 Baseline 高，就可以强力回应：

```text
Even without FFT-based blur-frame filtering, the FSAM3-based foreground extraction improves reconstruction quality and processing efficiency compared with standard 2DGS using the same raw input condition.
```

### Baseline + SAM3 vs Baseline + FSAM3 / F2DMAS w/o FFT

回答：

```text
提升是否只是 SAM3 带来的。
```

如果 FSAM3 更好，可以写：

```text
The improvement is not simply caused by using SAM3 as the segmentation backbone. Compared with SAM3-only masks, FSAM3 reduces background adhesion and fragmented regions through largest-component filtering, temporal consistency, and morphological post-processing.
```

### Baseline + FSAM3 / F2DMAS w/o FFT vs F2DMAS

回答：

```text
FFT 在完整 workflow 里的额外贡献。
```

如果 F2DMAS 更好，可以写：

```text
The comparison between F2DMAS w/o FFT and full F2DMAS shows that FFT-based blur-frame filtering further improves input stability before FSAM3 and 2DGS reconstruction.
```
