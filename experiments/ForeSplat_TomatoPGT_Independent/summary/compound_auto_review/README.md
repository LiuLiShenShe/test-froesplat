# 番茄复叶配对核验

打开同目录的 `index.html`。默认展示公制扫描中优先核验的复叶；切换“状态”可查看其余建议、歧义和未匹配条目。每条都可打开原图掩膜、候选 PLY、三维查看器和扫描证据。三视角叠图中，蓝色是官方参考点，橙色是预测网格采样点，绿色和粉色是两侧的测量端点。

核验页的叠图和照片预览已嵌入 HTML，单独打开此文件也可查看和切换。IDE 预览禁用脚本时只显示首条图片，完整核验请在浏览器中打开。原始 PLY 和三维查看器仍从项目原路径打开。

- `scan_summary.csv`：按扫描汇总复叶、子叶和建议状态。`registration.json` 是每个扫描的配准记录。
- `compound_match_suggestions.csv`：逐官方叶实例列出建议、备选、重叠、覆盖、端点和 `model_local_path`。没有可靠匹配的参考实例也保留。
- `provisional_leaf_measurements.csv`：端点通过自动筛选、且配准尺度比未触发复核的预填尺寸。长度是复叶基部到尖端的三维直线；宽度是同一中部横向位置的三维直线，不能用官方 `Thickness` 代替。

在页面选择确认、否决或无法判定。身份和端点可独立核验。页面只对已确认身份、已核验端点且公制检查通过的值统计 MAE/RMSE。决定保存在当前浏览器，可导出 CSV 作为持久记录；不会回写到原运行的 `compound_review.csv`、`batch_compound_pairs.csv` 或原始模型。

整株相似配准只用于确认几何对应关系，厘米值分别从原公制网格和官方参考读取。配准比例偏离 1 超过 20% 的公制扫描仍可复核身份，但暂不纳入尺寸误差。复叶与子叶分开；官方骨架边 ID 与点标签 ID 都记录，有点标注但没有可信骨架链接时保留点标签。缺少同口径参考面积，网格原始三角面面积不计入单侧叶面积误差。
